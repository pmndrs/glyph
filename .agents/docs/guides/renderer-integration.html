Integrate a renderer with Glyph

Build one public GlyphConfig, retain Text state, decode a borrowed ordered display list into host objects, and realize those objects with TypeGPU 0.12 and WebGPU.

One public integration boundary

A custom integration imports application-facing types from @pmndrs/glyph and construction helpers from explicit @pmndrs/glyph/config/* leaves. Portable raster packages and shader subpaths remain separate so unused formats, helpers, and shaders can tree-shake.

Current proof boundary. The TypeGPU example owns an offscreen texture and submits during transactional commit. A caller-owned canvas/context/pass seam remains unimplemented.

First success

import { glyph } from '@pmndrs/glyph';
import { glyphExample } from '@pmndrs/glyph-example-raster';
import { defineExampleConfig, TypeGpuExampleRendererDevice } from '@pmndrs/glyph-example-renderer';

await glyph.init();
const adapter = await navigator.gpu.requestAdapter();
if (adapter === null) throw new Error('WebGPU is unavailable');

const device = await adapter.requestDevice();
const rendererDevice = new TypeGpuExampleRendererDevice({ device, width: 768, height: 192 });
const handle = glyph.handle('typegpu:main', defineExampleConfig(rendererDevice));
const font = glyph.fontFace(new URL('./Inter-glyph-example.font.glb', import.meta.url), {
  format: glyphExample({ paletteSeed: 17 }),
});
await font.load();
const text = handle.createText({ font, text: 'Portable TypeGPU', fontSize: 64, width: 768, height: 192 });
glyph.shape();
if (handle.drawList.draws.length === 0) throw new Error('the renderer produced no draw');

glyph.init() is idempotent. glyph.handle(name, config) requires a unique nonempty handle name and infers the concrete handle. glyph.shape() publishes every dirty root through one engine batch; Text and root objects do not expose a second semantic flush.

Codec, command view, decoder, host draw

GlyphConfig.encode() selects the Codec that defines packed command-buffer data. Glyph's trusted internal projection produces a borrowed CommandBufferView with an ordered nested DisplayList. The configured renderer's decode(view) stages retained host objects. The host renderer later traverses or submits accepted objects.

Every borrowed sequence and byte slice expires when decode() returns. Renderer code may retain schema-created object identities and copied scalar state, never the view itself.

The complete GlyphConfig DSL

Field Required Responsibility
schema yes Host binding types projected within the root boundary.
fonts no Handle-relative raster-format map and default.
encode yes Codec descriptor for packed command data.
resolve yes Portable-resource realization and leases.
renderer yes Root-scoped decode, transform sync, and disposal.
root yes Anonymous/named host root and boundary construction.
commands no Initial command-buffer and retained-text capacities.

Actual example config

import type { Codec, GlyphConfigFor } from '@pmndrs/glyph';
import { defineGlyphConfig, resourceLease } from '@pmndrs/glyph/config/glyph';

export type ExampleGlyphConfig = GlyphConfigFor<
  typeof ExampleSchema,
  ExampleRoot,
  ExampleDrawList,
  Codec,
  ExampleFontFormats
>;

export function defineExampleConfig(device?: ExampleRendererDevice): ExampleGlyphConfig {
  const formatId = device?.shader.variant.formatId ?? exampleRendererShader.variant.formatId;
  return defineGlyphConfig({
    schema: ExampleSchema,
    fonts: { default: glyphExample.kind, formats: ExampleFontFormats },
    encode: ({ ids }) => ({ descriptor: exampleCodecDescriptor(ids) }),
    resolve: ({ format, resourceName, payload }) => {
      if (format !== formatId) {
        throw new TypeError(`example renderer shader "${formatId}" cannot render "${format}"`);
      }
      return resourceLease(Object.freeze({ name: resourceName, resource: payload }), () => undefined);
    },
    renderer: () => {
      const selectedDevice = device ?? new RecordingExampleRendererDevice();
      return {
        decode: (view) => selectedDevice.decode(view),
        syncTransforms: () => undefined,
        dispose: () => selectedDevice.reset(),
      };
    },
    root: {
      create: (context) => {
        if (context.fonts === undefined) throw new TypeError('example GlyphConfig must declare font formats');
        const extension = new ExampleRootImplementation(context.fonts, context.services);
        return context.create(extension, {
          boundary: Object.freeze({ name: context.name }),
          shape: { accepted: (drawList) => extension.accept(drawList) },
        });
      },
    },
  });
}

Optional command tuning is plain config data: { requestBytes, resultBytes, textUnits, limits }. Omit it until measurements justify changing defaults.

Schema and type inference

export const ExampleSchema: GlyphSchema<ExampleBindings, ExampleRootContext> =
  defineGlyphSchema({
    program: (_root: ExampleRootContext, program) => Object.freeze({ kind: 'example-program', program }),
    buffer: (_root, input) => Object.freeze({ kind: 'example-buffer', input }),
    material: (_root, material) => material,
    transform: (_root, transform) => transform,
    batch: (_root, input) => Object.freeze({ kind: 'example-batch', input }),
    instance: (_root, input) => Object.freeze({ kind: 'example-instance', input }),
    instanceSpan: (_root, input) => Object.freeze({ kind: 'example-instance-span', input }),
  });

The root recipe supplies its renderer-owned publication boundary once through context.create(...), and every schema callback receives it as the first argument. It can represent a scene node, render layer, or small semantic object. The direct helper and glyph.handle(name, config) infer inline structural configs. The exported package example names its GlyphSchema<ExampleBindings, ExampleRootContext> boundary so isolated declaration emit can describe the public library signature; it is not annotation ceremony imposed on application code.

Decode transactionally

GlyphRenderer.decode(view) is the only public decoder hook. It consumes resource, buffer, patch, retirement, and display-list phases synchronously. A replacement display list is already ordered. 

function retainDraws(frame: CommandBufferView<ExampleBindings>): readonly ExampleDraw[] {
  if (frame.displayList.kind !== 'replace') return [];
  const draws: ExampleDraw[] = [];
  for (const child of frame.displayList.value.children) {
    const input = child.value.input;
    const instances = child.kind === 'batch' ? child.instances : [child.value.input.instance];
    for (const instance of instances) {
      const primitive = instance.value.input;
      draws.push(Object.freeze({
        kind: child.kind,
        program: input.program.program,
        material: input.material,
        buffers: Object.freeze(Array.from(input.buffers)),
        resources: Object.freeze(Array.from(input.resources)),
        order: input.order,
        transform: child.kind === 'instance' ? child.transform : undefined,
        primitive,
      }));
    }
  }
  return Object.freeze(draws);
}
return Object.freeze({
  result,
  commit: () => publish(() => undefined),
  discard: () => { active = false },
});

Stage all fallible work before commit. Discard candidate-only objects on failure and preserve the previous accepted display list. Instrument by wrapping renderer(context) and its decode(view).

Construct one anonymous root and named siblings

root: {
  create: (context) => {
    if (context.fonts === undefined) throw new TypeError('example config must declare font formats');
    const extension = new ExampleRootImplementation(context.fonts, context.services);
    return context.create(extension, {
      boundary: Object.freeze({ name: context.name }),
      shape: { accepted: (drawList) => extension.accept(drawList) },
    });
  },
},

Services exist before the host root; context.create() activates the boundary and renderer. Call it once and return its result. The handle fronts its anonymous root. handle('hud') returns one live, idempotent, terminal named sibling. Roots cannot nest, and Text cannot exist without a root. 

const handle = glyph.handle('typegpu:main', config);
const worldText = handle.createText({ font, text: 'World' });
const hud = handle('hud');
console.assert(hud === handle('hud'));
const hudText = hud.createText({ font, text: 'Score: 42' });

Root names are customization labels, not inferred scene UUIDs. A scene-like host boundary belongs in the schema boundary object. TextGroup remains nested hierarchy and inheritance inside a root.

FontFace loading and handle binding

fonts: {
  default: 'glyphExample',
  formats: { glyphExample },
},

With fonts configured, root construction receives context.fonts with isLoaded, load, acquire, and peek. Acquire returns an independent immutable Font lease; peek borrows the store-owned value and must not be disposed. 

const Inter = glyph.fontFace(new URL('./Inter.font.glb', import.meta.url), {
  family: 'Inter',
  format: glyphExample({ paletteSeed: 17 }),
});
await Inter.load();
console.assert(Inter.isLoaded());
await Inter.glyphExample.load(); // exact raster format only

The main font must advertise every declared raster format or loading rejects. A synchronous Text constructor throws when its selected raster format is not loaded. React may suspend on the handle's exact format operation; its immutable context carries only the selected handle/root and never becomes another Glyph runtime.

Realize TypeGPU 0.12 resources

const root = tgpu.initFromDevice({ device });
const target = root
  .createTexture({ size: [width, height], format: 'rgba8unorm' })
  .$overrideFlags(GPUTextureUsage.RENDER_ATTACHMENT | GPUTextureUsage.COPY_SRC);
const targetView = target.createView('render');
const viewport = root.createUniform(d.vec2f, [width, height]);
const viewportGroup = root.createBindGroup(viewportLayout, { viewport });

const pipeline = root.createRenderPipeline({
  attribs: {
    position: positionLayout.attrib,
    uv: uvLayout.attrib,
    origin: originLayout.attrib,
    size: sizeLayout.attrib,
    color: colorLayout.attrib,
  },
  vertex: vertexMain,
  fragment: fragmentMain,
  targets: {
    format: 'rgba8unorm',
    blend: {
      color: { srcFactor: 'src-alpha', dstFactor: 'one-minus-src-alpha' },
      alpha: { srcFactor: 'one', dstFactor: 'one-minus-src-alpha' },
    },
  },
  primitive: { topology: 'triangle-list' },
});
pipeline.initSync();

The caller supplies and owns GPUDevice. Supplied geometry becomes vertex/index buffers; packed Codec lanes become instance buffers. Typed shaders come from @pmndrs/glyph-example-raster/typegpu. The integration adds target format, blending, layouts, and viewport projection.

Let the host renderer submit

The current offscreen proof records and submits inside its commit callback:

const encoder = root['~unstable'].createCommandEncoder();
const pass = encoder.beginRenderPass({
  colorAttachments: [{ view: targetView, clearValue: { r: 0, g: 0, b: 0, a: 0 }, loadOp: 'clear', storeOp: 'store' }],
});

for (const realized of realizedDraws) {
  pipeline
    .with(viewportGroup)
    .with(positionLayout, geometry.position)
    .with(uvLayout, geometry.uv)
    .with(originLayout, origin)
    .with(sizeLayout, size)
    .with(colorLayout, color)
    .with(pass)
    .withIndexBuffer(geometry.indices, 'uint16')
    .drawIndexed(realized.geometry.indexCount, realized.geometry.instanceCount,
      realized.geometry.indexStart, 0, realized.primitive.recordIndex);
}
pass.end();
device.queue.submit([encoder.finish()]);

The command/pass API is under TypeGPU 0.12's ~unstable surface.

Object First required
Glyph runtime Before glyph.handle(); await glyph.init().
Loaded FontFace selection Before synchronous Text creation; Text acquires its own immutable Font lease.
GPUDevice Before physical GPU resources; never for shaping.
Canvas Only for onscreen presentation.
GPUCanvasContext When configuring canvas presentation and acquiring its current texture.
Scene-like object Only if the host uses one; capture it in the root publication boundary.
Render pass During host draw recording, after retained state commits.
Camera/frame uniforms At host drawing or transform sync unless they affect semantic layout.

Ownership and disposal

text.dispose();
handle.dispose();
font.dispose();
rendererDevice.dispose();
device.destroy();

Handle disposal cascades roots, Codec state, and handle-relative font records. The renderer device destroys its TypeGPU resources but never the caller's device. Public disposals are idempotent; finalization is only a leak safety net for abandoned FontFace declarations.

Verification checklist

  1. Use only root Glyph imports, raster-format packages, and explicit shader subpaths.
  2. Infer the concrete handle without casts or explicit Glyph generics.
  3. Prove Codec lanes, capability selection, batching, and order.
  4. Receive ordered batches and root instances with no numeric IDs.
  5. Prove exactly-once resource lease acquisition, replacement, retirement, and disposal.
  6. Produce pixels from supplied geometry, buffers, bind groups, and a pipeline.
  7. Retain accepted draws across idle publications.
  8. Inject decode and commit failures; keep accepted state and discard candidates.
  9. Synchronize transforms without shape or Rust work.
  10. Prove anonymous-root projection and idempotent terminal named roots.
  11. Reconstruct physical state after device loss from loaded FontFace selections and desired Text state.
  12. Keep canvas, context, pass, shadows, targets, and post-processing under host ownership.

Current gaps—do not paper over these

Schema inference

defineGlyphSchema(schema) is direct, but the example still needs an explicit GlyphSchema<ExampleBindings, ExampleRootContext> variable annotation.

Exported config annotation

--isolatedDeclarations requires the exported config factory to name ExampleGlyphConfig; callback and handle types still infer from that single boundary.

Transform proof

The example transform sync is a no-op; Three supplies the live synchronization proof.

Host pass seam

The TypeGPU proof owns its offscreen target and submission; no caller-pass method exists.

Snippet checking

Repository docs validation does not compile fenced examples; snippets mirror checked package source.
