# Direct retained locator: source-only single-pass proof

20 October 2026. Read-only refinement of `fresh-causal-hybrid-20261020.md`, the original direct-operand brief, and the declared-field error addendum. No product source, Git state, process, build, test, profile or benchmark was changed. This establishes a *feasible control flow*, not compiled behavior or a speed result.

## Answer

**Yes, one selected-source pass is structurally possible on an admitted complete-owner retained preparation, while preserving the existing exact output intervals.** It requires changing the retained callback to populate one locator for *every* selected global record, including zero-mask rows, and supplying complete source ranges for each admitted owner. It does not require a second selected-row walk, a rope rank query per Codec operand, or a reset gather. The current code cannot do it unchanged: `planner_gather_owners` supplies `unpublished_source_intervals()`, `OwnerRanges` visits only those intervals, and `update_retained_source`'s zero-mask and position-only branches return without resolving the selected binding tuple. Those are bounded changes inside the existing retained walk.

The existing `OwnerRanges::next` (`codec_gather.rs:409–447`) maps `intervals: None` to exactly `0..owner.input.glyphs.len()`. `RetainedRope::update_ordered_ranges` (`retained_rope.rs:350–380, 1328–1430`) traverses disjoint ranges in storage order and invokes the callback once per visited source record. With the admission guard proving all active owners once, equal old/current source counts, no decorations and ordered `GatherRange` endpoints, full owner ranges cover each source row once in global source order. `append_retained_stream` already carries both source and record cursors; each selected `GatherSource` advances `record_cursor` once and each recordless source advances only the source cursor. Write the locator at that current global selected `record_cursor` before advancing it. For the first selected row of an owner, `record_cursor == owner.range.start.record`; after its last source, it equals `owner.range.end.record`. Contiguous, undecorated all-owner ranges mean no selected-record gap; assert final locator length equals `glyphs.len()` and final cursors pass `finish_retained()` before using direct input.

There is one bookkeeping subtlety: the current `append_retained_stream` clones the owner iterator, using one copy to yield rope ranges and another to identify the callback's current owner (`codec_gather.rs:654–795`). That is **two traversals of cheap owner descriptors already present in the packed retained implementation**, but only one source-record traversal and one binding selection per selected row in the proposed admitted direct branch. Do not add an owner prepass or second selection loop. If “one owner pass” is interpreted literally to exclude the existing clone, that stronger property is not proved by this implementation and would require changing the rope range/callback API or adding owner metadata storage; neither is needed to delete the field producer. Instrument owner-descriptor yields separately from source callbacks and `binding.select` calls to make the distinction visible.

## Minimum retained-walk changes

1. In `state.rs`, use the exact key, non-checkpoint, successful `prepare_retained_order(Gather)`, complete unique active frontier, same source count, no lifecycle/order/decorations and source-totality eligibility from the High addendum. The direct call to `planner_gather_owners` must pass full owner ranges (`intervals: None`) while still borrowing the same positioned arenas and current semantic masks. Its ordinary sparse packed call retains the current `unpublished_source_intervals()`. Do not replace the exact selected-output interval scope with `None`.
2. Split `CodecGatherWorkspace::begin_retained`'s validity into packed-column validity and metadata validity. Current code (`codec_gather.rs:570–598`) requires every full field length to equal selected length before it enables `retained_output_intervals`; this would reject a second `MetadataOnly` frame. Metadata mode proves source/selected counts, `glyphs`, slots and masks, clears the previous `dirty_mask_ranges` mask slots, and preserves `retained_output_intervals=true` without claiming field columns valid. Reserve locator capacity fallibly for the selected count before the callback; a provisional failure or uncertainty falls back to packed gather so the old authority decides public status/read order. Keep old packed capacity until successful direct Rust commit.
3. In `update_retained_source` (`codec_gather.rs:798–999`), preserve the same stable-ID, previous-selected, topology, `PlanGlyph`, placement and change-mask decisions. In the zero-mask selected branch, resolve the binding and call `select` to recover `strike_row` before returning. If the tuple cannot be proved consistent with the retained selection, abandon the direct attempt and use the packed path; packed zero-mask behavior must remain authoritative. In the position-only selected branch (`:999–1130`), retain its eligibility/legacy-semantic rules and metadata/mask writes but suppress its `semantic_f32` and `AlignedField` reads/writes in certified metadata mode; resolve the exact tuple for the locator there. The general changed-row branch already selects a binding/tuple and can write the locator at its `record_cursor` instead of calling `update_fields`. Recordless branches write no locator. All paths must either write exactly one locator for a selected row or stop/fallback; no stale locator from a previous preparation is valid.
4. To obtain `binding_index` without another search, let the existing `binding_for_font` lookup in `state.rs` return the `font_bindings` slice index together with `&FontRenderBinding`, and cache both in `RetainedGatherCursor`. The current closure uses a linear `.find()` (`state.rs:2549–2558`); adapt that single lookup rather than perform a second `.position()` or search at Codec load. Each locator stores checked paragraph index, local glyph index, binding index, packed strike/resource and strike row. The callback's owner descriptor currently has no `paragraph_index`; add it to the private `RetainedGatherOwner` or carry it alongside the same owner iterator. Do not search `planner.paragraphs` or the rope per operand. Direct row contexts index the call-scoped locator by global input ID, then borrow the paragraph's positioned view and binding by the stored checked indices.
5. A topology/selection stop returns the existing retained miss, but direct metadata cannot continue through `replace_retained_owners` or `append_from`, which materialize packed fields. Reset the provisional metadata and run the existing packed gather/rebuild. The source-totality certificate is an eligibility check, never a new public rejection. It covers all *declared* inputs, including unused/masked ones; unknown semantic fields, missing table shape, uncertain binding or sidecar allocation take packed fallback to preserve `SourceFieldMissing`, `InvalidRequest`/`ResultTooLarge` precedence and the E4 `legacy_semantic_field` rule. A successful direct admission uses only the one retained selected-source pass; a failed attempt may deliberately rerun packed authority.

## Why exact output scope survives

`begin_retained` clears prior nonzero-mask slots through the saved `dirty_mask_ranges` (`codec_gather.rs:590–598`). `write_change_mask` adds an output interval only for a nonzero *current* positioning mask (`:1870–1889`), while `replace_glyph` also marks genuine bounds/semantic-ID changes (`:1170–1188`). The zero-mask branch changes placement metadata and may call `replace_glyph`; the position-only and general branches write the same current mask. Those decisions are independent of whether a f32/u32 `AlignedField` slot is materialized. Thus traversing extra unchanged source rows to fill locators need not mark them dirty. Keep all current mask defaults and metadata comparisons; do not mark every selected row changed because every owner is in the frontier. The complete-mask-column shape should be checked for admission to avoid changing the fresh writer's missing-mask default (`ALL`) versus retained update's missing-mask default (`0`).

After the one retained walk succeeds, pass `gather.changed_output_intervals()` unchanged through `OwnedOutputScope::ChangedIntervals` (`state.rs:1954–1982`) into `OrderedPlanCompiler::prepare_retained_topology` (`ordered_plan.rs:1169–1210`). A narrow interval remains narrow, preserving clean-span admission/binding reuse; only the existing `sparse_output_intervals` rule may turn an *actual* `[0..P]` into full-dirty topology. This is the distinction the metadata reset cannot guarantee when it passes `output_scope=None`. Existing ordered physical indices, active-buffer masks, byte comparison, patch coordinates and host generations remain its authority. A code-level proof of *byte-identical interval arrays* for every changed owner still needs tests: full visits can expose a metadata change in a row formerly skipped by a narrower source interval. Compare interval count/endpoints and ordered comparison/patch bytes against packed retained output in the independent cold oracle, especially all-owner frontiers with sparse selected masks.

## Work accounting and stop conditions

Let `S` be source rows, `P` selected rows and `Z` selected rows that previously took zero-mask or position-only fast paths without selection. Successful direct admission performs one rope callback per source row and one locator write per selected row; up to `Z` additional `binding.select` calls occur in that same callback. It performs no second source/selection traversal. It replaces the E4 producer's 117,760 field writes (471,040 payload bytes) and later packed Codec field loads with `20P` locator payload writes and direct load-time source/table reads. On the E4 P=9,216 trace, `20P=184,320` logical bytes, before vector capacity, allocator and context costs. Full owner ranges can add source callbacks and rope COW work relative to an interval-filtered packed frame; compare actual visit, leaf/path-copy, allocation and interval counters rather than assuming they are free. Contexts should be resolved once per scalar row/four-lane group; count repeats across physical runs, live operation loads, SIMD groups/tails and 32-bit source reads. No net traffic or latency result follows from the byte subtraction.

Stop the retained variant if instrumentation shows a second selected walk, repeated owner/binding search per Codec load, stale/partial locator coverage, changed error/status precedence, widened exact output intervals or ordered comparison/patch work on otherwise equivalent data, or unacceptable direct↔sparse p95/peak. The preserved complete metadata reset remains a separately named fallback experiment if retained COW/selection cost dominates; its `output_scope=None` work widening must be measured, and its old half-mask threshold/short-run shaping/count-change admission/full-field writes must not be imported. This note authorizes no source work or measurement while the prior benchmark is live.
