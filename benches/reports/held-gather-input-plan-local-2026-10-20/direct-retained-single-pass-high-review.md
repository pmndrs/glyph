# High review: direct retained single-pass proof — 20 October 2026

**Verdict: source-feasible, not implementation-ready as written.** The proposed `intervals: None` gives one rope callback per old source row on an admitted complete-owner frame, but the same-pass certificate and provisional fallback do not yet preserve the old narrow packed result on every reachable miss. Fix that transaction boundary before dispatching an implementation. This is a narrow read-only review of `direct-retained-single-pass-proof.md` against current `b81756a5…` source with `codec_gather.rs` SHA-256 `e8c21cb9…`. ## What the source proves

`OwnerRanges::next` maps `intervals: None` to `0..owner.input.glyphs.len()` and clamps it to the old `GatherRange` source count. `RetainedRope::update_ordered_ranges` invokes its callback once for each visited old source record in sorted disjoint ranges. `append_retained_stream` clones the owner iterator: one copy supplies ranges, the other supplies callback ownership, so the claim is **one source-record pass**, not one descriptor pass. With an explicit guard that old ranges start at zero, are adjacent in source **and selected-record** space, end at the current source/selected lengths, and match every active owner exactly once, all selected records can receive one locator at the current `record_cursor`. The existing `finish_retained()` checks final cursor lengths; it is a postcondition, not a substitute for the pre-mutation adjacency guard. Empty/recordless owners must be included in that proof.

The interval distinction is sound in principle. `begin_retained` clears old dirty mask slots; `write_change_mask` and `replace_glyph` mark current selected-output changes. Full source traversal can fill locators while `changed_output_intervals()` remains exact, and `state.rs` can still pass `OwnedOutputScope::ChangedIntervals` to ordered compilation. However, all-owner dirt does **not** imply `[0..P]` selected-output dirt. Preserve the actual intervals and compare their endpoints, ordered admissions, binding reuse and patch bytes with the packed retained path. A newly visited zero-mask row could expose a metadata difference that the old narrow source interval did not inspect; treat that as a measured equivalence question, not a proved identical interval array.

The proposal also correctly names extra work: full ranges may increase rope callbacks, COW leaf/path copies and `dirty_mask_ranges.try_reserve` from the interval-filtered path; zero/position-only selected rows add `binding.select`. The E4 Bitmap warm publication already visits all 10,240 sources, but that is one fixture, not a bound for all admitted complete-owner frames. Count source callbacks, descriptor yields, selection calls, rope copied records/allocations and changed-output intervals on the same frozen input. Do not count 471,040 bytes of removed field writes as net savings until direct source loads, 20P locator traffic, four-lane assembly and direct→sparse rebuild costs are included.

## Necessary correction 1: certify before mutation or restore the exact packed base

The note says a certificate miss, locator allocation failure or topology/selection stop can reset and rerun packed gather. `update_ordered_ranges` constructs a replacement rope transactionally, but its callback has already modified `self.glyphs`, slots, masks, interval state and cursors before a later miss; `begin_retained` already zeroed old dirty-mask slots. A subsequent `gather.begin()` performs a **fresh full** packed gather, not the old retained narrow update. Fresh gather reads every declared field in earlier clean rows, so it may return `SourceFieldMissing` or allocation failure where the original narrow retained path would have succeeded. `source_f32/source_u32` and `gather_fields` make this observable for dynamic descriptors. Thus “packed authority” is insufficient unless the exact pre-attempt packed state and narrow scope are restored, or a separate proof establishes full-gather error/result equivalence for the admitted frame.

The cleanest single-source-pass design is a **non-mutating conservative pre-admission certificate** over the current owner shapes, validated program descriptors and registered binding table domains. It may overapproximate all registered bindings/program variants rather than scan glyphs; uncertainty means run the original packed retained path while its state is intact. Reserve the complete locator before `begin_retained`. The certificate must prove declared semantic/derived/optional columns and glyph/strike/resource table fields are total, including unused and inactive inputs; it must not read values or issue a public error. Prove that binding registration/disposal invalidates the gather key (`state.rs:622–689`) and that prepared glyph handles/selection parameters are package-owned for the certified frame. Then specify what happens on an unexpected **post-mutation** selection/topology or allocation miss: either retain an exact undo/checkpoint for all mutated gather metadata and invoke the original narrow packed route, or demonstrate with source and independent status tests that a fresh full gather has the same status, accepted bytes and allocation behavior for the restricted certificate domain. A bare fresh rerun is not enough, and a sidecar allocation error must not replace a packed success.

An alternative up-front selection/topology pass would allow a simpler direct mutation phase but is a second source traversal and must be reported as such. A transaction journal may cost O(P) metadata and peak bytes; it is transient but must be counted and cannot silently become a duplicate whole layout. Choose and prove one fallback strategy before implementation. `state.rs:1895–1933` clears gather-cache keys before the retained attempt, and `commit_update` at `:2287–2295` promotes a prior key when no prepared key exists; a typed `Packed | MetadataOnly` mode must survive both paths and must never promote stale full fields.

## Necessary correction 2: exact tuple and old mask semantics

`update_retained_source`'s zero-mask selected branch currently checks stable ID and old `PlanGlyph`, updates placement metadata, and returns **without** binding lookup or selection. The position-only branch can likewise return after its `ResolvedInputPlan`/legacy-field decision without calling `select`. Direct locators need the current `binding_index`, `strike`, `resource` and exact `strike_row`. `GatherSource.selection` stores only strike/resource (`selection_key`); it cannot recover `strike_row`. Add one selection in the same callback for each admitted selected zero/position-only row, before irreversible metadata writes for that row, and require a selected tuple consistent with the retained source key. Do not invent `strike_row` from the packed key or rely on the old selected flag alone. If lookup/select/key consistency is uncertain, take the exact packed fallback from correction 1, not a new public `FontBindingMissing` or a silently changed operand. Recordless rows get no locator.

Keep position-only `input_plan` eligibility and `legacy_semantic_field` behavior; the certificate must route unknown semantic descriptors to packed mode before any mutation. Suppressing actual `semantic_f32`/`AlignedField` reads in certified direct mode is valid only after that proof. Keep the current per-row semantic mask, including intentional empty-mask input for unchanged owners from `planner_gather_owners`; a complete stored mask column alone does not mean the effective `LayoutPlanInput` slice is nonempty. The Bitmap target has narrow as well as full masks. Never widen all of them to `ALL_SEMANTIC_CHANGES` to make direct compilation easier. Verify that source/table values omitted by a narrow packed update are semantically unchanged under the package-owned positioning mask, so direct load-time reads match the old packed operand bits for active runs.

## Readiness gate for the Medium brief

After the two corrections, the branch is ready for a bounded implementation attempt if its owner-contiguity guard, pre-admission certificate, typed cache transitions and exact fallback are specified in pseudocode. The independent oracle must include a custom valid descriptor with an unused missing declared field where **narrow retained succeeds but fresh full gather rejects**, plus a late topology/selection miss after earlier metadata writes; compare status, rollback and accepted bytes against the original packed route. Also test zero/position-only rows with distinct strike rows, recordless rows, full/narrow masks, direct→direct and direct→sparse transitions, renderer rejection and borrowed lease expiry. Instrument the 512/1,024 guard and absence of a second selected walk before timing. No arbitrary 5% floor applies: preserve a correct inconclusive whole variant for compatible combination, and admit performance only by the complete seven-family main/published/direct-prior gate.
