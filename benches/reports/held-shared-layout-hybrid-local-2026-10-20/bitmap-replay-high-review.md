# High review of Bitmap native replay authentication proposal

20 October 2026. Source review only, against restored HELD HEAD `940e11e426d1fd0e05ae5ed4aaf4480c52475d7f` and the selected one-discriminator brief `../bitmap-evidence-design.md`. No capture, replay, build, timing or source modification was performed.

**Decision: approve a narrower authentication implementation, conditional on an export-wrapper smoke gate.** The medium proposal identifies the right Rust parsers and ownership stages, but its six private package hooks and modified package image are not the smallest route. `src/shaper.ts::createRuntimeShaper` calls `WebAssembly.instantiate(module,{})`, then `readModule` reads only `instance.exports` and binds each function. The existing `benches/scripts/capture-shaper-live-memory.mts` already intercepts this instantiation for an exact supplied module. A package-owned runner can give `glyph.init({ wasm: exactCompiledModule })` a facade whose `exports` wraps the real functions, with the real `memory` unchanged. Those wrappers copy pointer-backed inputs before calls and returned result bytes immediately after calls. `fixture.ts` subsequently calls idempotent `glyph.init()` during import. This uses the _unmodified_ installed `28fd` archive and its exact shipped Wasm. It adds no public or diagnostic ABI, package source hook, or alternate writer. The first smoke gate must prove the facade is accepted, captures exactly one engine instance, leaves the fixture's committed status/draw counts intact, and observes the complete expected event sequence; otherwise stop. Source inspection establishes feasibility, not runtime success.

## Corrections required before replay

1. **Measure is not update.** `PlanTransport.prepareParagraph` writes one request and calls `measureParagraph(root,pointer,length,paragraph)` for each setter. Wasm `measure_paragraph` calls `measure_paragraph_with_shaper`, `measured_semantic_views`, `query_layout`, `FrameTransport::stage_query(root, pre-measure root revision, views)`, then `commit_measure`. That commit advances preparation revision as needed but does **not** advance renderer revision or `FrameTransport.publication_generation`. The proposed table's generic `#decodeResult` wording misses the common no-measurement path: `prepareParagraph` calls `#recordResultExtent`, with no `PlanPublication` object. Capture the raw query result at the export return, including its header and empty render-plan tables.
2. **Publication is batched.** `RenderPlanner.stage` writes each root's arena through `PlanTransport.stageUpdate`; `pmndrs_glyph_engine_update_batch` reads the existing batch-entry ABI, calls `update(..., grow_output=true)` in entry order, then stores per-entry result pointer/status. Replay each entry, not a synthetic aggregate. `update` computes `next_publication_generation`, calls `prepare_update_with_shaper`, obtains `prepared_plan` and `prepared_semantic_views`, lays out/encodes/stages, calls `commit_update`, then `FrameTransport::publish_success`. Capture request slices _before_ the batch export and every result _after_ it, before the package resumes. Reject duplicate root IDs within one batch unless their earlier results are independently captured before overwrite. No duplicate is assumed for this fixture.
3. **Transport and root lifetimes are separate.** `create_root` constructs `FrameTransport::new(requestCapacity,resultCapacity)`, creates `TextEngine` root, and reserves text capacity (zero means `DEFAULT_ROOT_TEXT_CAPACITY`). `reserve_root` first reserves request/result arenas and then nonzero text capacity; failed second stage can leave the transport grown. `reset_root` resets **only** derived engine state, preserving transport capacities and publication fence; `dispose_root` removes both. `FrameTransport` generation persists through reset and increments only on successful publication. Capture every create/reserve/reset/dispose, statuses, exact requested capacities and root IDs; replay them in order, including implicit `reserve_publish_capacity` during batched update. Copy requests into the native transport's own arena before `request_at_current`, preserving the pointer/length check. Do not create a new native `FrameTransport` for each publication or set generation from captured headers.
4. **Exact output witness is available earlier than `BorrowedPlanLease`.** A wrapper around `measureParagraph` or `textUpdateBatch` can copy the entire returned `ENGINE_RESULT_BYTE_LENGTH` from the real Wasm memory synchronously before the next package operation. This includes headers, semantic table, resource/buffer/patch/draw/retirement records and payload. For a batch, read result pointers/statuses from the existing generated `engineUpdateBatchEntry` schema after the call. Check each pointer/range and the generated result header before copying. `PlanPublication.bytes` is borrowed, but export-return copying is within that lifetime; it avoids a package hook at `RenderPlanner.consume`. The proposal's claim that actual Three target buffer generations and destination byte arrays can be snapshotted after acceptance is **not established**: `ThreeCommandBufferRenderer.#buffers` is private, while `inspectDraws` reports only draw/glyph counts. Do not claim a host-buffer witness. Authenticate exact encoded physical patch/payload bytes; later apply them to an independent byte-map oracle using the existing ABI/typed plan reader, and compare with a cold final plan. Target success is separately checked by the fixture/`commitState`.
5. **Native access is crate-test-local.** `frame_wire::parse_update_request`, `font_binding_wire::parse_font_binding`, `codec_wire::parse_codec`, `TextEngine::measure_paragraph_with_shaper`/`prepare_update_with_shaper`, and `FrameTransport` are `pub(crate)`, so a native integration test outside the crate cannot call them. A `#[cfg(test)]` child module under `engine/transport.rs` can also inspect its private arenas without an accessor or ABI. Reuse `ShaperRegistry` and the existing exact parsers. First implement authentication only; do not add work counters until all captured query/publication events pass.
6. **Byte equivalence is the gate.** `AlignedArena` capacity is based on explicitly resized block _length_, so matching create/reserve/implicit growth should reproduce serialized capacity fields. Pointer addresses, Wasm memory addresses, and memory-growth flags are outside the encoded result and need not match native. Compare result bytes, including status, revisions, generation, typed tables and physical payload, exactly. Record the first mismatching generated-ABI field for diagnosis, but do not normalize f32, signed zero, identities, generation, payload or unexplained headers into a passing result. Architecture-dependent divergence is a failed exact replay for this discriminator, not permission to claim Bitmap counts from a similar input.

The capture must record registration and disposal order for every font/Codec/binding/stack actually loaded when `fixture.ts` imports (it loads Inter, DotGothic and Fredoka), even though only Inter is used by the selected scene. It must take the exact bytes presented at `registerFont`, `registerFontBinding`, `registerCodec`, `registerFontStack`; no GLB re-decoding or label-derived request generation is allowed. The generated ABI in the installed package (`dist/text-shaper-abi.js`) supplies batch/result offsets; JSON records only event order, arguments, hashes and blob references. Stop if the runner cannot observe a successful call or if any blob/result is missing, even if final draw count is right.

The one-fixture ledger can choose whether physical ownership work merits a source deletion search. It cannot prove elapsed savings, seven-family parity, host GPU bytes, or an E3 revival.
