# Independent native Bitmap replay authentication review

20 October 2026. Read-only source and stored-evidence review at HELD HEAD `940e11e426d1fd0e05ae5ed4aaf4480c52475d7f`. I did not run capture, replay, build, timing, or quality gates, and did not edit source or Git.

## Findings

1. **[P1] Replay omits the shipping engine's initialization step, so the full native state is not authenticated before work counters.** `readModule` calls the Wasm `initialize` export before handing exports to the package (`packages/glyph/src/internal/text-shaper-module.ts:126–132`). The capture facade's `observed` set omits that export (`benches/labs/package/bitmap-native-replay.capture.mts:89–110`), and the native test starts with default `ShaperRegistry` and `TextEngine` and enters the event loop without calling their `initialize` methods (`packages/glyph/rust/shaper/src/engine/transport/bitmap_replay_auth.rs:68–85`). The real Wasm initializer calls both methods (`packages/glyph/rust/shaper/src/wasm.rs:110–120`); they reserve the shape/context/feature and gather buffers (`packages/glyph/rust/shaper/src/lib.rs:191–205`, `packages/glyph/rust/shaper/src/engine/state.rs:616–620`). The exact result-byte pass can coexist with different preallocation and later work. Add `initialize` to the facade's captured stateful exports and replay it first with the existing native methods, asserting status. Retain the current exact result comparison afterward. Until this is done, the trace proves result equivalence for captured successful calls, but not the claimed complete setup state for a physical-work or allocation ledger.

2. **[P2] Captured batch reservation is accepted without native replay.** The trace contains a successful `reserveUpdateBatch(1)` at sequence 3076 before the first publication. Wasm executes `UpdateBatchTransport::reserve` and grows its descriptor arena (`packages/glyph/rust/shaper/src/wasm.rs:444–449`, `packages/glyph/rust/shaper/src/engine/transport.rs:62–71`), while the native test's `reserveUpdateBatch` arm is a no-op (`packages/glyph/rust/shaper/src/engine/transport/bitmap_replay_auth.rs:167–168`). Per-entry engine outcomes and result bytes are still compared by the following `textUpdateBatch` arm; this gap concerns batch arena setup and the claim that every lifecycle/status event was natively reproduced. Keep a native `UpdateBatchTransport` and call its existing `reserve` with the captured count, asserting the captured status. The current direct ordered entry replay can remain explicit scope for the one-entry fixture; if batch transport work is later counted, exercise its existing `process` path and compare statuses then, without making native pointer addresses an equality requirement.
