## Findings

1. **P1 — Codec gather lane totals omit a real retained fast path.** `codec_gather.rs::update_retained_position_only` reads required semantic f32 inputs at lines 966–980 and writes required f32/u32 fields at lines 982–995. A successful position-only path therefore has zero reported dependency reads and field writes for that path. An attempted path can read some f32 values and return `false` before the general path, making even its attempted work invisible. The first replay's `97,280` f32 reads and `20,480` u32 reads per retained publication are valid only as counts from the two instrumented routines; the report cannot claim exhaustive gathered input reads. **Smallest observer fix:** after each successful `semantic_f32` read, increment one f32 read. Before each successful field `set`, capture the old value under `#[cfg(test)]`; after the `set`, increment one slot write and one changed slot only when old and new bits differ. Count one u32 input-lane read for each required placement-slot lane actually set. Exclude input-mask inspection, skipped lanes, the structural `placement_slots.set`, and default fills. Keep these hooks in this owner routine; do not infer work from masks in the replay.

2. **P2 — Accepted positioned source size is absent.** `state.rs:1876–1894` already computes `record_count` from active positioned glyph lengths for fresh gather, or from the retained source count reconciled with changed lengths. The diagnostic reports `gather_output_source_rows` from `gather.sources.len()` at lines 1943–1945, which is a gather-workspace output domain. It does not separately report the accepted positioned arena source total required by the brief. In all three publication buckets, the ledger shows `positioning.rows = 0` while gathered source output is `10,240`; zero means no revision-assignment visits in that _publication event_, not an empty accepted positioned arena. **Smallest fix:** after a successful gather, add the already computed `record_count` to a distinct `preparedPositionedSourceRows` field. Label it as the accepted positioned source total represented by this preparation. The reuse-ordered-plan branch does not compute `record_count`; do not silently substitute gather output or claim coverage there without an existing trusted count.
