# Bounded implementation brief: authenticate actual Bitmap replay first

**Scope:** one untimed `createTextBatch(1_024)` initial publication and one `alpha NNNN`→`bravo NNNN`→`alpha NNNN` cycle, each edit with 1,024 synchronous setters followed by one scene publication. Produce a complete authenticated trace and native exact-byte replay before adding any work counters. No product optimization, public entry, new Wasm export, cache, Codec, parser or layout. Keep E3 preserved and live source at restored `28fd` behavior.

## Gate sequence

1. **Facade smoke gate:** exact compiled module identity, exactly one wrapped shaper instance, original package archive unchanged, fixture initial publication succeeds, expected measure count/order and publication root/batch structure observed. Abort before native work if any expectation fails. If the facade is incompatible, stop and report that fact; a private modified package image would require a separate reviewed brief, not an implicit fallback.
2. **Capture completeness:** hash all registration wire bytes and all request/result slices. Preserve create/reserve/reset/dispose events and input statuses. Require full initial, forward and reverse cycles with successful `commitState`, expected text count, nonzero glyphs and no group error. The wrapper copies returned output synchronously before package reads another Wasm answer. No timing or profiler runs.
3. **Native exact authentication:** compare each query and publication result byte-for-byte, plus every event status and lifecycle sequence. Report first mismatch by generated ABI field and raw offset. Do not accept typed normalization of any physical, semantic, identity or revision data. A full-byte pass authorizes a later **separate** `cfg(test)` counter patch; a failure ends this discriminator.

The captured publication contains the complete Rust-authored patch/payload tables but not a verified snapshot of Three's private retained buffer arrays. For the later decision, build final physical buffer bytes by applying the captured patches with the package's existing typed plan reader/ABI and compare against a fresh cold-root output; retain exact buffer IDs/generations and ordered tables where that domain is stable. This is a physical oracle, not a second semantic executor. Do not attach a host-byte claim or a latency estimate to the authentication result.
