The producer is `state.rs::try_prepare_incremental_shape` around `5360–5430`: it checks old/new run topology and primary fallback, calls `build_sparse_shape_windows`, then may replace its first windows with `set_whole_shape_window`. Its `SparseWindowBuilder::visit` chooses the first window and `probe_end`. The new-side check is in `prepare_incremental_shape_scope` around `5535–5585`: it shapes the attempted range with the entire new run as context, rejects glyph ID zero for fallback, then calls `sparse_shape_boundaries_are_safe` on the temporary shaped arena; a failed new boundary returns `RetryWholeRun` and clears that arena. `concat_boundary_is_safe` around `7476` returns false both for missing cluster and unsafe flag, so the test probe must distinguish them **before** scratch is cleared.
