The selected wave stays within the existing transaction: bypass the old-text seed for one validated full replacement; combine single-owner text/style validation with routing; skip empty frame-section setup and writes; acknowledge already committed publication state without committing eleven stages again. General partial/multiple-record, lifecycle, style and geometry paths remain. No public API, ABI, semantic executor, persistent cache or storage design is introduced.

The deletion budget is concrete work, not elapsed time: one old UTF-16 seed copy per admitted full replacement, repeated owner routing per setter, empty-section setup/writer calls, and no-op stage commits for settled owners. Complexity remains proportional to authored text and required semantic/render records. Pending candidates reuse existing buffers; no duplicate semantic store is added. Unpublished owners can also have newer pending work, which must still commit before acknowledgement. Checked sizes, fallible growth, UTF-16 validation, independent split, accepted-output lifetimes, rejection and explicit retry remain requirements.

There is no evidence-backed parity-sized latency promise. The two matched profile passes are load-confounded diagnostics; their tail outliers do not rank variants. Even erasing three named scaffolding frames entirely would only represent about 1.22 sampled milliseconds per callback in one pass, and necessary work remains. Deferring render projection for 1,024 distinct final labels still derives every final row and may add a metadata store and traversal. The seven-family complete-operation evaluation decides this candidate; aggregate wins or statistical neutrality do not establish parity.
