The seven fixed workload families and held `#292 → #301 → #302 → draft #310` stack remain governing scope. Parity is false and post-parity boost waves remain zero. This supersedes the earlier broad new O(G) selection preflight. A Medium implementation is assigned but has not yet established its required independent cold-oracle baseline, source proof, patch or measured gain. A smaller repeatable win without meaningful seven-family regression may be retained; parity is still unproved. A candidate requires independent cold semantic and physical output, rejection/retry, API/ABI/peer/lifetime, browser/editorial hero, size, engine and whole-app memory gates, followed by exact unprofiled complete-operation comparison with same-machine main and published 0.1.0 across all seven families.
