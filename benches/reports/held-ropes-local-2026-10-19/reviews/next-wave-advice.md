## Ranked conditional options

1. **Fuse complete physical admission and leaf replacement inside the existing ordered rope updater.** In `packages/glyph/rust/shaper/src/engine/ordered_plan.rs:1107–1269`, `prepare_retained_topology` scans every physical instance, checks its input mapping and batch key, derives `instance_state`, compares it, and accumulates dirty slots. In the all-dirty branch it derives `instance_state` a second time while `try_from_exact` builds a new rope; otherwise it sorts dirty slots and derives them again in `update_ordered_ranges`. A complete-range path could call the existing `RetainedRope::update_ordered_ranges` (`retained_rope.rs:338–374`) once over `0..G`, performing admission, binding-dirt assessment, comparison, and replacement in the updater callback. Its 32-record leaf updater already copies one changed leaf and branch path once (`retained_rope.rs:1330–1420`). Keep provisional dirty/binding state local until the transactional updater succeeds; an invalid mapping must still return to the existing complete fallback, and allocation failure must preserve the old root. Delete the old complete scan plus second derivation only if the replacement passes. This removes one `instance_state` derivation per changed row and one ordered walk, without an O(G) shadow `InstanceState` vector, storage-format change, or second executor. Dense cost remains O(G) reads/writes and O(G) new leaf storage; sparse cost must remain proportional to dirty ranges plus touched leaf paths. **Falsify** if the updater's leaf cloning/summary work offsets the removed scan, if sparse admission or abort work grows, or if independent cold command/physical bytes, order, identity, rejection/commit, or lifetime oracles differ. The profile's named `prepare_retained_topology` inclusive row is only 13,499 sampled µs over 80 publications; inlining prevents treating it as a strict bound, but the profile does not establish a large elapsed opportunity here. A previous source-only prototype is not in this checkout and carries no evidence.

2. **Skip repeated codec-program lookup for full semantic-change masks in retained gather.** `codec_gather.rs:806–879` already caches the `ProgramDescriptor` by technique/variant, then calls `ValidatedCodec::input_masks_for_changes` for each selected row. `codec.rs:419–458` searches the same program again before its `ALL_SEMANTIC_CHANGES` / `force_all` branch returns all declared f32/u32 input bits. For the 5,120 all-mask rows per native cycle, the existing validated descriptor can supply those bit counts directly; leave the codec function for partial masks and any selection change whose proof is not local. This is a narrow deletion of a redundant `program_index` lookup, not an attempt to skip changed f32 data or codec execution. It preserves the packed SoA writer and should add no cache. **Falsify** if measured program lookup is immaterial, if direct masks differ for any capability/program/selection case, or if the full cold f32/u32 and command output changes. The profile gives `input_masks_for_changes` 13,998 self sampled µs over 80 publications and `update_fields` 56,582; neither number is a promised saving. This option is smaller than option 1 in mechanism and likely too small to justify its own full timing wave; it can be considered only in a coherent publication work-removal candidate.
