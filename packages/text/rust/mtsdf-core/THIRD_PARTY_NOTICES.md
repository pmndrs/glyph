# MTSDF core algorithm provenance

This package is an original Rust implementation maintained by `pmndrs/text`.
Its algorithm and differential tests reference Viktor Chlumsky's `msdfgen`,
which is distributed under the MIT License:

> Copyright (c) 2014–2025 Viktor Chlumsky

The complete upstream license is available at
<https://github.com/Chlumsky/msdfgen/blob/v1.13/LICENSE.txt>.

The implementation also incorporates design findings from the MIT-declared
`klyff_msdf` crate. No Klyff source file is copied into this package. See the
repository's MTSDF generation research concept for the reviewed versions,
license evidence, and disposition.
