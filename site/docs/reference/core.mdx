`@pmndrs/glyph/core` is for integrators: code that connects a renderer to the engine or adds a raster format.
Applications do not need it. This page lists every export with a one-line description. Functions and constants are
values; everything else is a type. Many of the types are also exported from `@pmndrs/glyph`; all of them can be
imported from `@pmndrs/glyph/core`.

For how the parts fit together, read [Renderer integration](/explanation/renderer-integration) and
[The render plan](/explanation/render-plan).

```ts
import { defineGlyphConfig, defineGlyphSchema, resourceLease } from '@pmndrs/glyph/core';
import type { CommandBufferView, GlyphRenderer, GlyphTextController } from '@pmndrs/glyph/core';
```

## Config

A `GlyphConfig` is what `glyph.handle(name, config)` takes.

| Export                 | Kind      | Description                                                                                         |
| ---------------------- | --------- | --------------------------------------------------------------------------------------------------- |
| `defineGlyphConfig`    | function  | `(config) => config`. Returns its argument; exists to infer and tie together the config's types.    |
| `GlyphConfig`          | type      | `<Root, Bindings, RendererResult, FontFormats, Boundary, CodecValue>`: `schema`, `encode`, `resolve`, `renderer`, `root`, optional `fonts` and `commands`. |
| `GlyphConfigFor`       | type      | `<Schema, Root, RendererResult, CodecValue?, FontFormats?>`: a nameable `GlyphConfig` derived from a schema type. |
| `GlyphConfigHandle`    | type      | `<Config>`: the handle type `glyph.handle` returns for a config.                                    |
| `GlyphConfigBindings`  | type      | `<Config>`: the binding set of a config's schema.                                                   |
| `SelectedGlyphConfig`  | type      | The immutable part of a config visible while a root is constructed (everything except `root`).      |
| `GlyphFontConfig`      | type      | `{ default, formats }`: the raster formats a handle accepts by key, and the default key.            |
| `GlyphCommandCapacity` | type      | Initial capacities for a root's publications: `limits`, `requestBytes`, `resultBytes`, `textUnits`, optional `maxTextUnits` (default 65,536). |
| `GlyphCommandLimits`   | type      | Fixed limits of one root: `maxParagraphs`, `maxClusters`, `maxLines`, `maxRegions`, `maxExclusions`, `maxInlineObjects`, `maxSlotsPerBand`, `maxOutputBytes`. |
| `Codec`                | type      | What `encode()` returns: `{ descriptor, capabilitySet?, dispose? }`.                                |
| `EncodeContext`        | type      | Argument of `encode()`: `{ integration, ids }`.                                                     |
| `ResolveContext`       | type      | Argument of `resolve()`: `format`, `resourceKind`, `resourceName`, `payload`, `resources`, `previous`, `signal`. |
| `ResourceLease`        | type      | `{ value, disposed, dispose() }`: a resolved resource and its release.                              |
| `resourceLease`        | function  | `(value, release) => ResourceLease`. The lease's `dispose()` calls `release` at most once. Throws `TypeError` for a non-object value or a non-function release. |
| `RendererContext`      | type      | Argument of `renderer()`: `boundary`, `signal`, `codec`, optional `defaultRenderer`.                |

| `MSDF_GLYPH_TABLE_LAYER_STEP`    | constant | `4096`. The multiplier that packs a glyph's atlas layer into the fourth table value.        |
| `slugSchema`                     | constant | The Slug technique schema. Buffers `rect`, `color`, `glyph`.                                |
| `slugCodec`                      | constant | The registered Slug codec.                                                                  |
| `SLUG_GLYPH_RECORD_STRIDE`       | constant | `40`. Bytes per glyph in the baked Slug records.                                            |
| `SLUG_GLYPH_TABLE_STRIDE`        | constant | `16`. `u32` words per glyph in a page's `glyphs` table.                                     |
| `SLUG_PLANE_UNITS_PER_EM`        | constant | `2048`. Units per em of the Slug curve plane.                                               |
| `SlugBandResidency`              | class    | Keeps one Slug page's band curves resident for the glyphs drawn. `new SlugBandResidency(curves, references, glyphTable)`; `use(lane, start, end, stride)` admits the glyphs of an instance range and returns a `SlugAdmission` or `undefined`; `entries` and `lines` expose the resident texels. |
| `SlugAdmission`                  | type     | What one `use` call changed: `grew`, `firstLine`, `endLine`, `rows`.                        |
| `SLUG_RESIDENT_BAND_CURVE_WIDTH` | constant | `1024`. Texels per line of a resident band-curve texture.                                   |
| `decorationSchema`               | constant | The schema of decoration rectangles. Buffers `rect` (`left`, `top`, `width`, `height`) and `packed` (`color`, `flags`). |
| `createDecorationCodecProgram`   | function | `(options) => CodecProgram`. The program that publishes decoration rectangles.              |
| `DecorationCodecProgramOptions`  | type     | `{ techniqueId, programId, transformMode, system }`.                                        |

## Example

The functions an integration calls most, in one typechecked module:

```ts
import {
  compileCodec,
  createRasterCodecProgram,
  defineCodecBuffers,
  id,
  msdfCodec,
  normalizeCodecCapabilitySet,
  schemaCodecBuffers,
  selectBitmapStrikePpem,
} from '@pmndrs/glyph/core';
import type { CodecDescriptor } from '@pmndrs/glyph/core';

const capabilitySet = normalizeCodecCapabilitySet({
  capabilities: ['storage-buffers', 'alias-vec2', 'alias-vec4', 'ordered-direct'],
  maxBufferBytes: 16 * 1024 * 1024,
  updateAlignment: 4,
  coalesceGapBytes: 128,
  rangeCallPenaltyBytes: 256,
  maxBuffersPerDraw: 8,
  maxResourcesPerDraw: 4,
  maxIndirectDraws: 0,
  fragmentationBudget: 8,
  wholeBufferThresholdBasisPoints: 7_500,
});

const system = defineCodecBuffers({
  stableGlyphId: { id: id.buffer('example/stable-glyph'), scalar: 'u32', lanes: ['stableGlyphId'] },
  placementSlot: { id: id.buffer('example/placement-slot'), scalar: 'u32', lanes: ['placementSlot'] },
});

const descriptor: CodecDescriptor = {
  capabilitySets: [capabilitySet],
  programs: [
    createRasterCodecProgram(msdfCodec, {
      namespace: 'example',
      system,
      capabilitySet,
      transformMode: 'direct',
    }),
  ],
};

const wire: Uint8Array = compileCodec(descriptor);
const msdfBuffers = schemaCodecBuffers(msdfCodec.schema); // rect, color, effectColor, effect
const ppem: number = selectBitmapStrikePpem([{ ppem: 16 }, { ppem: 32 }], 14, 2); // 32
```
