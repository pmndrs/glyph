  Every entry here was hit for real. Each is one paragraph: what you see, why, what to do.

## The declared format is not in the GLB

{/* symptom: `FONT_FACE_FORMAT_UNAVAILABLE`. cause: raster options are part of the raster key — `msdf` default (64/8)
≠ `{ raster: msdf, options: { emSize: 32 } }`; a baked GLB never re-bakes. fix: one shared constant for the bake and
the declaration; `await face.formats()` to see what the GLB carries. */}

## Text throws "not loaded"

{/* symptom: `createText` or `text.font =` throws synchronously. cause: imperative text cannot suspend; the selection
was not awaited. fix: `await Inter.load()` (or `await Inter.slug.load()`) first. React suspends instead. */}

## An outer `<Text>` without a font

{/* symptom: mount error naming `font`. cause: only nested Text inherits. fix: pass `font` on the paragraph. */}

## Nothing draws in plain three.js

{/* symptom: a Text is in the scene, `renderer.render` shows nothing. cause: no `glyph.shape()` call — R3F does it for
you, imperative code does not. fix: call `glyph.shape()` after edits and before `renderer.render`. */}

## A span boundary moved

{/* symptom: `text.spans` differs from what was authored. cause: the boundary split a grapheme cluster and was
resolved forward to the cluster end — a base keeps its style. fix: author on cluster boundaries. */}

## Two scenes, one root

{/* symptom: an error naming two scenes. cause: a root binds at most one `Scene`. fix: `handle('other')` for the
second scene; in R3F, a `GlyphProvider handle={three('other')}` around the portal. */}

## Nothing changes with `fixed` capacity

{/* symptom: text stops updating; `commitState()` stays `pending`. cause: desired UTF-16 length exceeds the root's
`size`; the last draw is kept by design. fix: shorten, or `root.setCapacity`. */}

## `caretAt` returns `undefined`

{/* symptom: measurement works, interaction does not. cause: measurement is desired-state, `caretAt` is
accepted-state — nothing has been shaped yet. fix: shape once (R3F: wait a frame), or use `measure()`/`glyphs()`
for desired positions. */}

## Disposing in the wrong order

{/* symptom: a text renders nothing after its face was disposed. cause: leases are counted; a disposed face keeps the
text alive until the text disposes, but nothing new can bind. fix: text → group → root/handle → face. */}

## No WebGPU on the LAN

{/* symptom: WebGL2 on `http://10.0.0.x`, WebGPU on localhost. cause: `navigator.gpu` needs a secure context.
fix: HTTPS or a tunnel; the page still renders on WebGL2. */}

## CJK renders nothing

{/* symptom: a Noto Sans CJK bake has empty outlines. cause: the current baker reads TrueType outlines; CFF-only
faces produce none. fix: a TrueType CJK face (M PLUS 1p, Nanum Gothic, ZCOOL XiaoWei). Tracked upstream. */}

## Each letter lit separately

{/* symptom: a custom lit material shades glyphs as individual objects. cause: the normal was derived from
per-glyph em space (`renderCoordinate`). fix: derive it from `positionLocal` normalized by the paragraph's ink. */}

## Leading opens up with a fallback face

{/* symptom: one line is much taller. cause: `lineHeight` is resolved per cluster and clamps leading at zero; a
face with tall ascent/descent wins. fix: faces with similar vertical metrics, or a `lineHeight` that fits the
tallest. */}

## A font load rejects again and again

{/* symptom: repeated fetches after a failed load. cause: a rejected load is evicted so a retry is a new operation —
by design — and something keeps retrying. fix: an error boundary (`GlyphProvider errorFallback` for font errors) so
the failure is shown once rather than re-rendered. */}
