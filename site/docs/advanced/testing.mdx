## Node

```ts
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { msdf } from '@pmndrs/glyph/raster/msdf';

/** Shapes and measures without a renderer, scene, camera, or canvas. */
export async function lineCountAt480(fixture: BlobPart): Promise<number> {
  await glyph.init();
  const app = glyph.handle('test:measure', ThreeConfig);
  const Inter = glyph.fontFace(new Blob([fixture]), { format: msdf }); // a test's font is declared like an app's
  try {
    await Inter.load();
    const label = app.createText({
      font: Inter,
      text: 'Hello',
      style: { fontSize: 32 },
      constraints: { width: { mode: 'at-most', size: 480 } },
    });
    const lines = label.measure().lineCount;
    label.dispose();
    return lines;
  } finally {
    app.dispose(); // text → handle → face
    Inter.dispose();
  }
}
```

```ts no-check
import assert from 'node:assert/strict';
import { readFile } from 'node:fs/promises';
import test from 'node:test';

test('a short label is one line at 480', async () => {
  assert.equal(await lineCountAt480(await readFile('fixtures/inter.font.glb')), 1);
});
```

## Headless Chromium

```bash
# apps/benchmarks — the conformance suite through Playwright's Chromium
node scripts/run-headless.mts --suite conformance --dpr 1 --samples 3 --warmup 1 --port 5181

# use the machine's browser instead of the Playwright-managed one
PMNDRS_GLYPH_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome-stable node scripts/run-headless.mts --suite conformance
```

| Control | Meaning |
| --- | --- |
| `--dpr` | device pixel ratio the page is measured at (0 < dpr ≤ 4) |
| `--samples`, `--warmup` | frames measured and frames discarded first |
| `--target`, `--scenario` | one case instead of the suite |

## CI has no WebGPU

| Job | Runner | What it sees |
| --- | --- | --- |
| static checks | `ubuntu-24.04` | types, lint, unit tests; no browser |
| package size | `ubuntu-24.04`, pull requests | the delivery graphs against the PR base |
| runtime | `ubuntu-24.04`, 30 min | Node gates, then the browser conformance suite in the runner's system Chromium — WebGL2 |

## What to assert

| Layer | Assert on |
| --- | --- |
| shaping | exact glyph ids, clusters, positions, flags — not counts |
| layout | `measure()` fields under exact constraints: `lineCount`, `width`, `contentWidth`, baselines |
| rendering | pixel comparisons with an error envelope for filtered formats; exact for Bitmap |
| lifecycle | `commitState()` transitions, `gpuBytes`, disposal order and lease balance |

```ts
import { glyph } from '@pmndrs/glyph';

text.commitState(); // { status: 'pending' } — desired, not yet accepted
glyph.shape();
text.commitState(); // { status: 'committed', revision } — or { status: 'failed', error }
```

{/*
write
- Question: what is a good assertion here?
- Paragraph 1: exactness where the engine is exact — shaping and layout are deterministic integers, so assert the
  value, not a count or a range; a count that happens to match hides a reorder. Pixels are exact only for Bitmap;
  the filtered formats get an envelope you state.
- Paragraph 2: lifecycle through the public surface: `commitState()` says unbound, pending, committed, or failed
  with the error; `gpuBytes` says what a root retains; a lease test needs a positive control that a lease is
  genuinely held, or its silence is vacuous.
- Paragraph 3: the determinism rule: no sleeps, no timer cushions, no retries, no regenerated goldens as a fix.
- Shape: three paragraphs.
