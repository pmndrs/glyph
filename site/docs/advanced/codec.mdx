write · intro
- Question: who decides what a vertex shader reads per glyph, if the planner does not know my shader?
- Say: the planner knows, per glyph, where it sits, how big it is, what colour and effects it carries, and what the
  font's raster record says about it; a codec is the small straight-line program that turns those facts into the
  exact lanes a shader reads, plus the declaration of which buffers those lanes live in; the technique's author
  writes the program once, the renderer assembles it into a descriptor once per handle, the planner runs it for
  every glyph on every accepted update and ships the results as patches.
- Anchor: "a tiny assembler whose only instructions are load, add, subtract, multiply, convert, store".
- Shape: three sentences, then the figure.

write · keypoints (pmndrs `<Keypoints>`, four items, one clause each)
- A technique schema declares the buffers and their lanes; a program fills every lane exactly once from semantics
  and bindings.
- The program is straight-line arithmetic — `add`, `sub`, `mul`, constants, `toF32` — compiled to at most 32
  live registers and 128 operations.
- Ids are hashes of names: buffer ids are 16-bit, technique and program ids 32-bit, all derived from the strings you
  pass.
- Storage batches split on technique, program, resource, and depth; draws additionally split on material, clip,
  order, and — in `direct` transform mode — transform.

## Step 1 — declare the technique

```ts
import { id } from '@pmndrs/glyph/config/codec';
import { defineTechniqueSchema } from '@pmndrs/glyph/config/schema';

export const sdfSchema = defineTechniqueSchema({
  technique: 'studio.sdf', // the wire identity; `pmndrs.` is reserved for the shipped formats
  scope: 'glyph', // one binding row per glyph; 'strike' and 'resource' also exist
  binding: {
    // values the font's raster records supply per row, read by name in the program
    f32: ['bearingX', 'bearingY', 'width', 'height', 'u0', 'v0', 'uSpan', 'vSpan'],
    u32: ['page'],
  },
  buffers: {
    // what the shader will read, one record per instance; the lane count is the vector width
    rect: { id: id.buffer('studio.sdf/rect'), scalar: 'f32', lanes: ['left', 'top', 'width', 'height'] },
    uvRect: { id: id.buffer('studio.sdf/uv-rect'), scalar: 'f32', lanes: ['u0', 'v0', 'uSpan', 'vSpan'] },
    color: { id: id.buffer('studio.sdf/color'), scalar: 'f32', lanes: ['red', 'green', 'blue', 'alpha'] },
    page: { id: id.buffer('studio.sdf/page'), scalar: 'u32', lanes: ['page'] },
  },
  resources: { atlas: { kind: 'texture-array', format: 'rgba8unorm' } }, // named payloads a draw binds
  render: { resource: 'atlas', geometry: { kind: 'synthetic-quad' } },
  glyphOrigin: { buffer: 'rect' }, // lanes 0–1 of `rect` are the glyph origin, for measurement queries
});
```

| Field | Rule |
| --- | --- |
| `technique` | a nonempty string; `id.technique()` hashes it to the 32-bit wire id; `pmndrs.` is refused for third-party plan programs |
| `scope` | `'glyph'`, `'strike'`, or `'resource'` — how many binding rows the font supplies |
| `binding` | names the raster record fields the program may read, typed `f32` or `u32`; names are unique across both lists |
| `buffers` | each has an `id` from `id.buffer(name)` (nonzero, 16-bit, unique in the schema), one `scalar`, and 1 to 4 named lanes |
| `resources` | `buffer`, `texture`, `texture-array`, `geometry`, or `group`, by name; at most one may be `cardinality: 'many'` |
| `render` | which resource a draw binds and what geometry it realises; `synthetic-quad` is the default and needs no resource |
| `glyphOrigin` | optional; names an `f32` buffer with at least two lanes whose first two lanes are the glyph origin |

## Step 2 — write the program

```ts
import { id } from '@pmndrs/glyph/config/codec';
import { f32, techniqueProgram, u32 } from '@pmndrs/glyph/config/codec-program';
import { defineCodecBuffers } from '@pmndrs/glyph/config/schema';
import { msdf, msdfSchema } from '@pmndrs/glyph/raster/msdf';

// The renderer's own lanes. `stableGlyphId` is required; `transformIndex` only under `indexed` transforms.
const system = defineCodecBuffers({
  stableGlyphId: { id: id.buffer('my-renderer/stable-glyph'), scalar: 'u32', lanes: ['stableGlyphId'] },
  transformIndex: { id: id.buffer('my-renderer/transform-index'), scalar: 'u32', lanes: ['transformIndex'] },
});

export function msdfBody() {
  const p = techniqueProgram(msdfSchema, { textEffects: msdf.textEffects, system });
  const { inlineOrigin, blockOrigin, fontSize, color, outline, shadow } = p.semantics;
  if (outline === undefined || shadow === undefined) throw new Error('MSDF declares outline and shadow');
  const { bearingX, bearingY, width, height, uvOriginX, uvOriginY, uvSizeX, uvSizeY, uvMaxX, uvMaxY, page } = p.binding;

  return p.compile({
    rect: [
      f32.add(inlineOrigin, f32.mul(bearingX, fontSize)),
      f32.sub(blockOrigin, f32.mul(bearingY, fontSize)),
      f32.mul(width, fontSize),
      f32.mul(height, fontSize),
    ],
    uvRect: [uvOriginX, uvOriginY, uvSizeX, uvSizeY],
    uvBounds: [uvOriginX, uvOriginY, uvMaxX, uvMaxY],
    color: [color.red, color.green, color.blue, color.alpha],
    effectColor: [outline.color, shadow.color],
    page: [shadow.offsetXEm, shadow.offsetYEm, outline.widthEm, u32.toF32(page)],
  });
}
```

| Semantic | Type | Meaning |
| --- | --- | --- |
| `inlineOrigin`, `blockOrigin` | `f32` | the glyph's pen position in paragraph-local units |
| `fontSize` | `f32` | resolved size, so `binding × fontSize` is a length in paragraph units |
| `color.{red,green,blue,alpha}` | `f32` | the resolved paint; the engine has no background |
| `outline.{color,widthEm}` | `u32`, `f32` | present only when `textEffects` lists `outline`; the colour is packed RGBA |
| `shadow.{color,offsetXEm,offsetYEm}` | `u32`, `f32`, `f32` | present only when `textEffects` lists `shadow` |
| `inverseFontSize` | `f32` | present when `inverseFontSize: true`; Slug asks for it |
| `transformIndex`, `stableGlyphId` | `u32` | system lanes; `compile` stores them into your system buffers for you |

{/*

- Question: what can a program read, and what must it write?
- Paragraph 1: `techniqueProgram(schema, { system, textEffects?, inverseFontSize? })` hands back three things —
  `semantics`, what the engine knows per glyph; `binding`, the typed record values named in the schema; and
  `compile`, which takes exactly one value tuple per declared buffer. The values are expression handles, not
  numbers; nothing runs until the planner runs it.
- Paragraph 2: the rules `compile` enforces — every declared buffer present, no undeclared buffer, exactly
  `lanes.length` values of the buffer's scalar, and one `compile` per builder; then it appends the system stores
  (`stableGlyphId` always, `transformIndex` when the system declares it) and lowers the expression graph to
  registers, failing if more than 32 are live at once.
- Paragraph 3: this body is exactly what the shipped MSDF plan program's `codecBody` does; a renderer using MSDF
  never writes it — it is here so you can see one that is real. Your own technique's body is the same shape with
  your names.
- Anchor: "you write arithmetic on names; the compiler picks the registers".
- Avoid: the opcode numbers; they are internals.
- Shape: three paragraphs under the table.

## Step 3 — make it a program

```ts
import { id, type CodecCapabilitySet, type CodecIdFactory } from '@pmndrs/glyph/config/codec';
import { createRasterCodecProgram } from '@pmndrs/glyph/config/raster';
import { defineCodecBuffers } from '@pmndrs/glyph/config/schema';
import { msdfPlanProgram } from '@pmndrs/glyph/raster/msdf';

const system = defineCodecBuffers({
  stableGlyphId: { id: id.buffer('my-renderer/stable-glyph'), scalar: 'u32', lanes: ['stableGlyphId'] },
  transformIndex: { id: id.buffer('my-renderer/transform-index'), scalar: 'u32', lanes: ['transformIndex'] },
});

export const capabilitySet: CodecCapabilitySet = {
  capabilities: ['storage-buffers', 'alias-vec2', 'alias-vec4', 'ordered-direct'],
  maxBufferBytes: 16 * 1024 * 1024,
  updateAlignment: 4,
  coalesceGapBytes: 128,
  rangeCallPenaltyBytes: 256,
  maxBuffersPerDraw: 8,
  maxResourcesPerDraw: 4,
  maxIndirectDraws: 0,
  fragmentationBudget: 8,
  wholeBufferThresholdBasisPoints: 7_500,
};

// `ids` comes from `encode({ ids })`; every id it derives is collision-checked for this handle.
export const msdfProgram = (ids: CodecIdFactory) =>
  createRasterCodecProgram(msdfPlanProgram, {
    namespace: 'my-renderer', // with the technique id and an optional programName, this is the program id
    system,
    capabilitySet,
    transformMode: 'indexed',
    allocationMode: 'ordered',
    ids,
  });
```

| Mask | Bits | Effect |
| --- | --- | --- |
| `storageKeyMask` | technique, program, resource, depth | which keys separate **storage batches** — the buffers glyphs are packed into |
| `drawKeyMask` | the above plus material, clip, order, and transform in `direct` mode | which keys end a **draw span** |
| bit values | technique 1, resource 2, program 4, material 8, clip 16, depth 32, order 64, transform 128 | how a mask reads on the wire |

## Step 4 — put programs in a descriptor

```ts
import { compileCodec, id, type CodecCapabilitySet, type CodecDescriptor, type CodecIdFactory } from '@pmndrs/glyph/config/codec';
import { createRasterCodecProgram } from '@pmndrs/glyph/config/raster';
import { defineCodecBuffers } from '@pmndrs/glyph/config/schema';
import { msdfPlanProgram } from '@pmndrs/glyph/raster/msdf';

const system = defineCodecBuffers({
  stableGlyphId: { id: id.buffer('my-renderer/stable-glyph'), scalar: 'u32', lanes: ['stableGlyphId'] },
});

const capabilitySet: CodecCapabilitySet = {
  capabilities: ['storage-buffers', 'alias-vec2', 'alias-vec4', 'ordered-direct'],
  maxBufferBytes: 16 * 1024 * 1024,
  updateAlignment: 4,
  coalesceGapBytes: 128,
  rangeCallPenaltyBytes: 256,
  maxBuffersPerDraw: 8,
  maxResourcesPerDraw: 4,
  maxIndirectDraws: 0,
  fragmentationBudget: 8,
  wholeBufferThresholdBasisPoints: 7_500,
};

export function descriptor(ids: CodecIdFactory): CodecDescriptor {
  return {
    capabilitySets: [capabilitySet],
    programs: [
      createRasterCodecProgram(msdfPlanProgram, {
        namespace: 'my-renderer',
        system,
        capabilitySet,
        transformMode: 'direct', // no transformIndex lane: each draw carries its own transform
        allocationMode: 'ordered',
        ids,
      }),
    ],
  };
}

// What `encode` returns. The handle compiles and registers the descriptor at once; this is the same preflight.
export const encode = (context: { readonly ids: CodecIdFactory }) => {
  const value = descriptor(context.ids);
  compileCodec(value);
  return { descriptor: value };
};
```

| Limit | Value |
| --- | --- |
| capability sets per descriptor | 1 to 8; no two equivalent; every one referenced by some program |
| programs per descriptor | 1 to 32; program ids unique |
| `(capabilitySet, technique, variant)` | unique per descriptor |
| buffers per program | 16; buffer ids unique within a program |
| operations per program | 128 |
| registers | 32, allocated for you |
| capability set | must include `ordered-direct` or `stable-indirect`; `maxBufferBytes`, `maxBuffersPerDraw` (≤ 16), `maxResourcesPerDraw`, `fragmentationBudget` nonzero; `updateAlignment` a power of two ≤ 256 |

## The decoration program

```ts
import { createCodecProgram, id, type CodecIdFactory, type CodecProgram } from '@pmndrs/glyph/config/codec';
import { techniqueProgram } from '@pmndrs/glyph/config/codec-program';
import { defineCodecBuffers, defineTechniqueSchema, schemaCodecBuffers } from '@pmndrs/glyph/config/schema';

const system = defineCodecBuffers({
  stableGlyphId: { id: id.buffer('my-renderer/stable-glyph'), scalar: 'u32', lanes: ['stableGlyphId'] },
});

// Rows are resource-free and fill the gather lanes directly: the f32 lanes are the rectangle,
// the u32 lanes carry the packed colour and flags.
const decorationSchema = defineTechniqueSchema({
  technique: 'pmndrs.decoration',
  scope: 'glyph',
  binding: { u32: ['color', 'flags'] },
  buffers: {
    rect: { id: id.buffer('my-renderer/decoration/rect'), scalar: 'f32', lanes: ['left', 'top', 'width', 'height'] },
    packed: { id: id.buffer('my-renderer/decoration/packed'), scalar: 'u32', lanes: ['color', 'flags'] },
  },
});

export function decorationProgram(ids: CodecIdFactory): CodecProgram {
  const p = techniqueProgram(decorationSchema, { system });
  const { inlineOrigin, blockOrigin, fontSize, color } = p.semantics;
  return {
    ...createCodecProgram(
      ids.technique(decorationSchema.technique),
      ids.program(decorationSchema.technique, 'my-renderer'),
      p.compile({
        rect: [inlineOrigin, blockOrigin, fontSize, color.red], // gather lanes 0–3 already are the rectangle
        packed: [p.binding.color, p.binding.flags],
      }),
      [...schemaCodecBuffers(decorationSchema), { id: system.stableGlyphId.id, scalar: 'u32', vectorWidth: 1 }],
      'direct',
      'ordered',
    ),
    primitiveKind: 'decoration',
    resourceKindMask: 0, // legal only for decoration programs
```

## How the lanes reach your shader

```ts no-check
// three's reference realisation of one lane, from packages/glyph/src/three/internal/material-realizer.ts
const runStart = TSL.uniform(0, 'uint').onObjectUpdate(({ object }) => object?.userData.pmndrsGlyphRunStart ?? 0);
const instance = TSL.instanceIndex.add(runStart); // the span's recordIndex + this instance
const rect = TSL.storage(attribute, 'vec4', attribute.count).setPBO(true).element(instance);
```

| Plan side | three.js side |
| --- | --- |
| every program buffer appears in the plan's `buffers` table per storage batch, identified by `(id, generation)` and sized in bytes | a `StorageInstancedBufferAttribute` per buffer, item size = the buffer's lane count, named `_pmndrsGlyph_<bufferId>` |
| its contents arrive as `patches` whose payloads are exactly the lanes the program wrote | `write`, `fill`, and `copy` are staged with merged upload ranges; `allocate-or-resize` and `retire` are handled when the buffer is bound |
| each `draw` names the buffers it reads and a span `recordIndex`, `recordCount` | `instanceCount = recordCount`; `userData.pmndrsGlyphRunStart = recordIndex`; the shader reads `instanceIndex + runStart` |
| under `indexed` transforms the `transformIndex` lane selects a row | four `vec4` columns at `transformIndex × 4` in the shared `_pmndrsGlyphTransforms` attribute |
| under `direct` transforms `transformId` is set on the draw | one matrix per mesh, `matrixAutoUpdate` off |
