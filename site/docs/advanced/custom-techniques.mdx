<Intro>
  Bitmap, MSDF, and Slug are ordinary raster formats built on a public contract. A third-party format defines its
  descriptor and decoder, optionally a portable baker, a shader realization, and a three.js plan program — and then
  declares on a FontFace, loads through the hooks, stacks, and batches exactly like the built-ins.
</Intro>

```ts
import { defineRasterFormat, defineRasterResourceId } from '@pmndrs/glyph';

export const acmeSdf = defineRasterFormat({
  kind: 'acme.sdf',
  // descriptor, options normalization, decode(artifact) → data, resources, records
});
```

## Pieces

| Piece | Entry | Job |
| --- | --- | --- |
| format | `defineRasterFormat` | descriptor, raster key, decode portable data, partition and pack records |
| resources | `defineRasterResourceId` | named portable resources a shader expects |
| baker | `defineRasterBaker` / `rasterBake` (`/bake`) | produce the artifact at build time |
| shader | `/tsl/*` or `/typegpu/*` | the canonical realization for a backend |
| three program | `registerThreeRasterPlanProgram` (`/three`) | binds the shader and material factory to the plan |
| material typing | augment `ThreeTextMaterialContextMap` at your `kind` | `defineTextMaterial` stays exhaustive |

## Registration order

> [!WARNING]
> `registerThreeRasterPlanProgram` refuses a format registered after a runtime has already read the registry, and
> names the format. Import format modules before the first handle is created.

## Declaring and using it

```ts
const Acme = glyph.fontFace('/fonts/acme.font.glb', { format: { raster: acmeSdf, options: { spread: 4 } } });
const font = useFont('/fonts/acme.font.glb', { format: { raster: acmeSdf, options: { spread: 4 } } });
```

{/* prose: the format's `kind` is its key — `Acme.acme` is not a thing; a custom key resolves through the handle's
config font map when you name it as a string. Materials see the augmented map branch for your kind. */}
