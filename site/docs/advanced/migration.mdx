## R3F

```tsx no-check
// before
<Text font={font} paint={{ color: '#fff' }} contentBox={{ width: { mode: 'at-most', size: 6 }, wrap: 'word' }}>
  Hello <TextSpan paint={{ color: '#ffd166' }}>world</TextSpan>
</Text>
```

```tsx
import { Text } from '@pmndrs/glyph/react';
import { useMsdf } from '@pmndrs/glyph/react/msdf';

export function Greeting() {
  const font = useMsdf(url); // declares through glyph.fontFace; suspends until loaded
  return (
    <Text font={font} style={{ color: '#fff' }} layout={{ wrap: 'word' }} constraints={{ width: { mode: 'at-most', size: 6 } }}>
      Hello <Text style={{ color: '#ffd166' }}>world</Text>
    </Text>
  );
}
```

## Imperative

```ts no-check
// before
const loader = new FontLoader();
const font = await loader.loadAsync({ input: url, raster: { technique: msdf } });
const text = new Text({ font, text: 'Hello', paint: { color: '#fff' } });
scene.add(text);
const box = text.layout();
text.shape();
renderer.render(scene, camera);
```

```ts
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { msdf } from '@pmndrs/glyph/three/msdf';

await glyph.init();
const app = glyph.handle('app', ThreeConfig);
const Inter = glyph.fontFace('/fonts/Inter.glb', { format: msdf });
await Inter.load();

const label = app.createText({ font: Inter, text: 'Hello', style: { color: '#fff' } });
scene.add(label);
const box = label.measure(); // desired state, no publication
glyph.shape(); // every dirty root, once
renderer.render(scene, camera);
```

{/*
write
- Question: what does the imperative loop look like now?
- Two sentences: the runtime is explicit — `init` once, a named handle, a declared face — and everything else is the
  same five lines in a different vocabulary; `measure()` never publishes and `glyph.shape()` publishes everything
  that is dirty, so the order "edit, measure, shape, render" is the loop. Traversal shapes too, but swallows the
  error; the explicit call is where a rejection throws.
- Shape: one paragraph between the two blocks.

notes · internals
- the proof sequence `glyph.init() → glyph.handle() → face.load() → handle.createText() → scene.add(text) →
  glyph.shape() → renderer.render(scene, camera)` — D-304
- `Text` construction is token-guarded: "Three Text must be created with handle.createText() or an R3F Text
  component" — `three/text.ts:630–632`
- traversal shape swallows into `text.error` — `three/text.ts:478–486`
*/}
