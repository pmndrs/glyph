---

<Intro>
  The current API replaced an implicit shared runtime with an explicit root and named handles, made roots the batching
  boundary, split `paint` and `contentBox` into `style`, `layout`, and `constraints`, renamed the layout query, moved
  publication to `glyph.shape()`, and removed the offset-taking edit helpers. Each old form maps to exactly one new form.
</Intro>

| Before | After | Why |
| --- | --- | --- |
| `new FontLoader().loadAsync({ input, raster })` as the loader | `glyph.fontFace(source, { format })` + `load()`; hooks; `loadFont` for renderer-free code | fonts are declarations over one shared resource graph |
| implicit engine domain on first font use | `await glyph.init(); glyph.handle('main', ThreeConfig)` | explicit, disposable, several may coexist |
| `new Text(props)` | `handle.createText(props)` / `handle(name).createText(props)` | every text belongs to a root |
| `TextGroup` as the batch with `capacity`/`compositing` | the root owns capacity and compositing; `TextGroup` is a parent | one planner per root; groups organize |
| `text.shape()` / `group.shape()` | `glyph.shape()` | one publication call for every dirty root |
| `text.layout()` | `text.measure()` | measurement is an action; `layout` is the flow-policy property |
| `paint: { color }` | `style: { color }` | one inherited presentation object |
| `contentBox: { width, wrap, align }` | `layout: { wrap, align }` + `constraints: { width }` | flow policy and the parent's box are separate inputs |
| `<TextSpan>` | nested `<Text>` | one component |
| `insertText`, `deleteText`, `replaceText`, `setSpan`, `removeSpan` | `text.text = next` / `text.set({ text })` | assignment derives the minimal edit |
| `useFont({ input, raster })` per technique subpath | `useFont(source, { format })`; typed `useMsdf` / `useBitmap` / `useSlug` | one implementation, typed wrappers |
| `loadFont(input, { technique, options })` | `loadFont(input, { raster, options })` | "technique" is Codec vocabulary; the public term is raster format |
| `@pmndrs/glyph/core` | `defineGlyphConfig` and friends from the root entry | one integrator contract |

## R3F

```tsx
// before
<Text font={font} paint={{ color: '#fff' }} contentBox={{ width: { mode: 'at-most', size: 6 }, wrap: 'word' }}>
  Hello <TextSpan paint={{ color: '#ffd166' }}>world</TextSpan>
</Text>

// after
<Text font={font} style={{ color: '#fff' }} layout={{ wrap: 'word' }} constraints={{ width: { mode: 'at-most', size: 6 } }}>
  Hello <Text style={{ color: '#ffd166' }}>world</Text>
</Text>
```

## Imperative

```ts
// before
const loader = new FontLoader();
const font = await loader.loadAsync({ input: url, raster: { technique: msdf } });
const text = new Text({ font, text: 'Hello' });
const box = text.layout();
text.shape();

// after
await glyph.init();
const three = glyph.handle('main', ThreeConfig);
const face = glyph.fontFace({ baked: url });
await face.load();
const text = three.createText({ font: face, text: 'Hello' });
const box = text.measure();
glyph.shape();
```
