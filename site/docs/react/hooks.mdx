## What a hook does

![What a font hook does: the source becomes a FontFace cached per handle; a loaded selection returns the mounted Font lease, otherwise the hook suspends on the load.](/examples/diagrams/hook-flow.svg)

{/*
write
- Question: what is cached, where, and by whom?
- Say, reading the figure left to right: the source and format become one `FontFace` per handle, keyed by the
  source's identity and the format's canonical descriptor, so two components asking for the same URL share one
  declaration. The handle says which exact raster that declaration means and whether it is loaded; if it is, the
  hook hands back a mounted lease at once, otherwise it suspends on the face's load. The lease is the component's
  own and is released when it unmounts; there is no second cache beside Glyph's resource graph.
- Shape: three sentences.

notes · internals
- the selected handle: the nearest provider's, else the default — `react.ts:253–266`
- one `FontFace` per handle per key; a disposed face is re-declared — `react.ts:667–683`
  (`reactFontFaceResource`, `glyph.fontFace(input, config)`)
- key = source identity + canonical format descriptor JSON — `font-face.ts:303–305`, `:763–772`
  (`fontFaceSourceKey`: string, `URL`, or object identity), `:774–789` (`fontFaceFormatIdentity`)
- the handle answers which exact raster the declaration denotes and whether it is loaded —
  `three/handle.ts:157–168`, `font-face.ts:339–347` (`FontFaceHandleStore`)
- the mounted lease: acquired on first subscribe, disposed on last unsubscribe — `react.ts:723–746`
  (`createMountedFontStore`), `three/handle.ts:144–150` (`acquireThreeHandleFont`)

## preload

```ts
import { useMsdf } from '@pmndrs/glyph/react/msdf';

void useMsdf.preload('/fonts/inter.font.glb'); // Promise<void>, at module scope
```

{/*
write
- Question: how do I avoid the first-render waterfall?
- Say: call `preload` at module scope; it starts the load on the default handle and returns the actual Promise, so
  a later render finds `isLoaded()` true and never suspends. Say "default handle" plainly: a provider with its own
  handle is not warmed by this.
- Shape: two sentences.

notes · internals
- starts the default handle's load and keeps the Promise by key; a rejection evicts it so the next call retries —
  `react.ts:632–645`
- default handle only: it awaits `defaultThreeHandle()`, which runs `glyph.init()` if needed — `react.ts:389–407`
- the later render finds `isLoaded()` true and never calls `use()` — `react.ts:662`
- the wrappers forward their format — `react/msdf.ts:18–19`, `react/bitmap.ts:18`, `react/slug.ts:17`
- in use — `apps/r3f-hello-world/src/app.tsx:29–36`
*/}

## clear

```ts
import { useMsdf } from '@pmndrs/glyph/react/msdf';

useMsdf.clear('/fonts/inter.font.glb');
```

{/*
write
- Question: how do I let a font go?
- Say: `clear` drops the hook's declaration for that key on the default handle and disposes the face it declared; a
  component that is still mounted keeps its own lease until it unmounts, so nothing on screen disappears.
- Shape: two sentences.

notes · internals
- drops the preload entry and, on the default handle, the hook's declaration for that key, then disposes that
  `FontFace` — `react.ts:646–656`
- a mounted component's lease is independent and survives — `react.ts:723–746`; D-302 ("clear ... does not
  invalidate an independently mounted Font")
- disposing a face releases only its graph leases; nodes retire when nothing reaches them — D-298
*/}

## StrictMode and Suspense

| Event | Effect |
| --- | --- |
| mount / unmount / remount | leases acquire and release; the face is not disposed |
| Suspense retry | the same stable promise; no second fetch |
| load rejection | the record is evicted so the next render can retry |
| `clear()` while mounted | the mounted lease survives |

{/*
write
- Question: will StrictMode's double mount or a Suspense retry fetch twice?
- Say, one sentence per row: a mount takes a lease and an unmount releases it, and the face outlives both; a retry
  reads the same Promise the first render suspended on, so nothing is fetched again; a rejected load is evicted so
  the next render gets a fresh attempt rather than a cached failure; `clear()` under a mounted component changes
  nothing that component can see.
- Shape: four sentences.

notes · internals
- acquire on first subscriber, release on last — `react.ts:728–743`; `useSyncExternalStore` drives it — `:664`
- one Promise per selection and format, cached until the face releases it — `font-face.ts:502–503`, `:525`;
  rejection deletes it — `:520–523`; the aggregate load behaves the same — `:393`, `:404–407`
- the face-owned lease is published before the Promise fulfils, so the retry render sees `isLoaded()` — D-300
- [verify] StrictMode double-invocation is covered by a test: `docs/packages/glyph.md:619` names "React paragraph
  lease accounting under StrictMode"; find the spec file under `packages/glyph/src` (a `.test.ts` or `.test.tsx` file) and cite it
*/}

## Custom formats

```tsx
import { glyph } from '@pmndrs/glyph';
import { Text } from '@pmndrs/glyph/react';

const Acme = glyph.fontFace('/fonts/acme.font.glb', { format: 'acme' }); // a key the handle's config registers

<Text font={Acme}>no hook needed</Text>;
```
