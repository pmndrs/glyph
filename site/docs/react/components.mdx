<Intro>
  `<Text>` and `<TextGroup>` are the same three.js objects the imperative API creates, reconciled by React Three
  Fiber. Ordinary use needs no provider: the first text initializes the runtime and a default handle. A
  `GlyphProvider` selects a handle or root you made yourself and can name fonts for its subtree.
</Intro>

```tsx
import { Text, TextGroup } from '@pmndrs/glyph/react';

<TextGroup renderOrder={1}>
  <Text font={inter} style={{ fontSize: 0.5 }} layout={{ wrap: 'word' }} constraints={{ width: { mode: 'at-most', size: 6 } }}>
    Hello <Text style={{ color: '#ffd166' }}>world</Text>
  </Text>
</TextGroup>
```

</details>

### Nested Text

{/* prose: a nested `<Text>` is an inline run: inherits font, style, and material; accepts only `children`, `font`,
`style`, `material`; no transform, no Object3D; a box prop is named and rejected at mount rather than dropped. */}

### Fonts

{/* prose: a loaded `Font` from a hook renders immediately; a FontFace selection or a string is checked with
`isLoaded()` and suspends on its stable load promise only when not ready. An unknown string throws
`FONT_FACE_NOT_FOUND`. */}

## `<GlyphProvider>`

```tsx
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { GlyphProvider } from '@pmndrs/glyph/react';

await glyph.init();
const hud = glyph.handle('hud', ThreeConfig);

<GlyphProvider handle={hud('overlay')} fontFaces={{ Inter: '/fonts/inter.font.glb' }} fallback={null}>
  <Text font="Inter">HP 100</Text>
</GlyphProvider>;
```

| Prop | Meaning |
| --- | --- |
| `handle` | a `ThreeHandle` (its anonymous root) or a named `ThreeRoot` from `handle(name)` |
| `fontFaces` | `{ Name: source \| face \| { src, format } }` — names for `font="Name"` in this subtree |
| `fallback` | Suspense fallback while mapped faces load |
| `errorFallback` | node or `(error: FontLoadError) => node`; catches only font load errors, rethrows the rest |

{/* prose: the provider captures its initial `handle` and `fontFaces` and throws if either prop changes — remount
with a `key` to select another. It disposes only faces it declared from shorthand entries, never an externally
created handle or face. `fontFaces` and `fallback` add a local Suspense boundary. `Text`/`TextGroup` expose no
handle prop. */}

## The default handle

{/* prose: without a provider, the first mounted text initializes `glyph` and creates one module-owned `ThreeConfig`
handle with a root per R3F store; the initialized path is synchronous, so ready renders never call `use()`. */}

## Two scenes

{/* prose: a root binds at most one `Scene`. A portal into another Scene needs its own root — wrap that subtree in a
`GlyphProvider handle={three('portal')}`. */}

## Commit timing

{/* prose: components construct their objects during R3F host commit, so React `Activity` can pre-render hidden text;
property changes call `set()` and `invalidate()`; R3F's frame runs `glyph.shape()` before the host renders. */}
