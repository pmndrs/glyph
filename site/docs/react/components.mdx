<Intro>
  `<Text>` and `<TextGroup>` are the same three.js objects the imperative API creates, reconciled by React Three
  Fiber. Ordinary use needs no provider: the first text initializes the runtime and a default handle. A
  `GlyphProvider` exists to select a handle you made yourself.
</Intro>

```tsx
import { Text, TextGroup } from '@pmndrs/glyph/react';

<TextGroup compositing="independent">
  <Text font={inter} style={{ fontSize: 0.5 }} layout={{ wrap: 'word' }} constraints={{ width: { mode: 'at-most', size: 6 } }}>
    Hello <Text style={{ color: '#ffd166' }}>world</Text>
  </Text>
</TextGroup>
```

## `<Text>`

<details>
<summary>Props</summary>

| Prop | Type | Notes |
| --- | --- | --- |
| `font` | `Font \| FontStack` | required on an outer Text; inferred technique |
| `children` | string, number, nested `<Text>`, arrays | the paragraph's content |
| `style` | `PropertyList<TextStyle>` | inherited by nested spans |
| `layout` | `PropertyList<ParagraphLayout>` | outer Text only |
| `constraints` | `PropertyList<Constraints>` | outer Text only |
| `rasterPixelRatio` | `number` | raster density override |
| `material` | `ThreeTextMaterial` | see Materials |
| `capacity` | `{ size, policy }` | standalone capacity |
| `pixelSnapping` | `boolean` | Bitmap vertex snapping |
| `onError` | `(error) => void` | retained traversal errors |
| `ref` | `Ref<Text>` | the three.js object — `measure()`, `breakApart()`, … |
| …`Object3DProps` | | `position`, `rotation`, `scale`, `name`, events |

</details>

### Nested Text

{/* prose: a nested `<Text>` is an inline run: inherits font and style, accepts only `children`, `font`, `style`,
`material`; no transform, no Object3D; a box prop is named and rejected at mount rather than dropped. */}

## `<GlyphProvider>`

```tsx
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { GlyphProvider } from '@pmndrs/glyph/react';

await glyph.init();
const hud = glyph.handle('hud', { ...ThreeConfig, decode: instrumentedDecoder });

<GlyphProvider handle={hud}>
  <TextGroup>…</TextGroup>
</GlyphProvider>;
```

prop. Context is constructor injection only — no second engine, renderer, scene, or canvas. */}

## The default handle

{/* prose: without a provider, the first mounted text `use()`s one shared promise that calls `glyph.init()` and
creates a module-owned `ThreeConfig` handle; wrap in Suspense if you want a fallback while it initializes. */}

## Commit timing

{/* prose: components register their objects with R3F during host commit, so React `Activity` can pre-render hidden
text; property changes apply and call `invalidate()`; the next traversal publishes or syncs transforms before the
host builds its render list. */}
