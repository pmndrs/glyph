### Fonts

| `font` value | What happens |
| --- | --- |
| a `Font` from `useMsdf`/`useSlug`/`useBitmap` | renders now |
| a `FontFace` or a member (`Inter`, `Inter.slug`) | `isLoaded()` → renders now; otherwise suspends on the face's one load Promise |
| a string | provider `fontFaces` first, then the root catalog by family; unknown throws `FONT_FACE_NOT_FOUND` |

{/*

## `<GlyphProvider>`

```tsx
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { GlyphProvider, Text } from '@pmndrs/glyph/react';

await glyph.init();
const hud = glyph.handle('hud', ThreeConfig);

<GlyphProvider handle={hud('overlay')} fontFaces={{ Inter: '/fonts/inter.font.glb' }} fallback={null}>
  <Text font="Inter">HP 100</Text>
</GlyphProvider>;
```

| Prop | Meaning |
| --- | --- |
| `handle` | a `ThreeHandle` (its anonymous root) or a named `ThreeRoot` from `handle(name)` |
| `fontFaces` | `{ Name: url \| face \| { src, format } }` — names for `font="Name"` in this subtree |
| `fallback` | Suspense fallback while mapped faces load |
| `errorFallback` | node or `(error: FontLoadError) => node`; catches only font load errors, rethrows the rest |

## Commit timing

| Event | What runs |
| --- | --- |
| mount | R3F constructs the three.js `Text` at host commit with `args` from the first render |
| prop change | `set(update)` then `invalidate()` in a layout effect, only when the desired state differs |
| `pixelSnapping` change | remount |
| each frame | `renderer.render` → `scene.updateMatrixWorld` → the root's draw object → `glyph.shape()` |
| unmount | the object is disposed by R3F; the hook's mounted `Font` lease is released |

{/*
write
- Question: when does my change reach the scene?
- Say, one sentence per row: the object is built when R3F commits the host tree, which is why `Activity` can
  pre-render hidden text; a prop change becomes one `set()` and an `invalidate()`, skipped when nothing differs;
  `pixelSnapping` is immutable on the object, so changing it remounts; publication happens inside three's own
  `updateMatrixWorld`, so `renderer.render` is the frame hook and you need none of your own; on unmount R3F disposes
  the object and the hook releases its lease.
- Shape: five sentences, ending on "no frame hook is required".

- construction at commit — `react.ts:519–521` (constructor args once), `:544–549` (`args`, `ref`)
