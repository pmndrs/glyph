<Intro>
  A text material is a factory. Rust carries only a numeric id; three.js calls your factory when it needs a material
  for a concrete Bitmap, MSDF, Slug, or decoration pipeline, hands you that pipeline's shader nodes and the root it
  belongs to, and takes back any `NodeMaterial`. The default is one call away; a lit, reflective, glowing word is a
  few lines past it.
</Intro>

```ts
import { defineTextMaterial } from '@pmndrs/glyph/three';

const material = defineTextMaterial((context) => context.createDefaultMaterial());

const label = three.createText({ font: Inter, text: 'Custom', material });
```

## The context

```ts
defineTextMaterial((context) => {
  if (context.kind === 'decoration') return context.createDefaultMaterial(); // underline, overline, line-through
  switch (context.format) {
    case 'pmndrs.bitmap': context.shader; // position, clipPosition, atlasUv, coverage, color
    case 'pmndrs.msdf':   context.shader; // position, atlasUv, fillCoverage, outlineCoverage, shadowCoverage, color, opacity
    case 'pmndrs.slug':   context.shader; // position, renderCoordinate, coverage, color, opacity
  }
  context.root; // { name, scene, drawRoot } — which root this material is being built for
  return context.createDefaultMaterial();
});
```

| Field | Meaning |
| --- | --- |
| `kind` | `'glyph'` or `'decoration'` |
| `format` | glyph branches only: `'pmndrs.bitmap' \| 'pmndrs.msdf' \| 'pmndrs.slug'`, or a custom format's literal key |
| `shader` | that pipeline's TSL output nodes |
| `position` | final renderer-local position including Codec transform indirection — always `positionNode` |
| `root` | `ThreeRootContext`: the root's `name`, its `scene`, its `drawRoot` |
| `createDefaultMaterial()` | the built-in realization for this branch |

{/* prose: the union is closed over `ThreeTextMaterialContextMap`; a custom Three raster augments the map at its
literal format key, so `switch (context.format)` stays exhaustive without casts. Decoration is a `kind`, not a
format — it is not pretending to be a raster. */}

## Node table

| Node | Type | Meaning |
| --- | --- | --- |
| `coverage` / `fillCoverage` | `float` | antialiased fill |
| `outlineCoverage`, `shadowCoverage` | `float` | MSDF rings, fill already subtracted so they never double-count |
| `color` | `vec3` | unpremultiplied composite of fill, outline, shadow |
| `opacity` | `float` | style opacity × coverage |
| `atlasUv`, `renderCoordinate`, `clipPosition` | — | format-specific inputs; Bitmap alone publishes `clipPosition` because it snaps to the pixel grid |

## The base contract

> [!IMPORTANT]
> A custom material must keep what the default sets: `positionNode = context.position`, `DoubleSide`, `transparent`,
> `depthTest: false`, `depthWrite: false`, `NormalBlending`. Miss `positionNode` and the glyphs collapse to the
> origin; miss `depthTest: false` and batched glyphs z-fight.

```ts
const material = new MeshPhysicalNodeMaterial({
  blending: NormalBlending,
  depthTest: false,
  depthWrite: false,
  side: DoubleSide,
  transparent: true,
});
material.positionNode = context.position;
```

## Lit text

```ts
defineTextMaterial((context) => {
  if (context.kind !== 'glyph' || context.format !== 'pmndrs.msdf') return context.createDefaultMaterial();
  const material = new MeshPhysicalNodeMaterial({ /* base contract */ });
  material.positionNode = context.position;
  material.colorNode = context.shader.color;
  material.opacityNode = context.shader.opacity;
  material.metalnessNode = float(0.6);
  material.roughnessNode = float(0.4);
  material.normalNode = normalize(vec3(lean.x, lean.y, 1)); // a fake curvature from paragraph-local position
  return material;
});
```

{/* prose: lights and an environment map do the rest. Derive the normal from `positionLocal` normalized over the
paragraph's measured ink — per-glyph em space (`renderCoordinate`) lights every letter as its own object. The landing
wordmark is this material plus bloom and a lens flare from `useRenderPipeline`. */}

## Decorations

```ts
defineTextMaterial((context) => {
  const value = context.createDefaultMaterial();
  if (context.kind === 'decoration') value.colorNode = context.shader.color.mul(0.75);
  return value;
});
```

{/* prose: underline, overline, and line-through are planned as their own ordered batches with their own material
instances; one factory selects for both without splicing decoration geometry into a glyph draw. */}

## Where a material applies

```ts
import { span } from '@pmndrs/glyph/three';
import { txt } from '@pmndrs/glyph';

const glow = defineTextMaterial(...);
three.createText({ font: Inter, text: txt`Status ${span(glow, { color: '#4ade80' })`online`}` });
three.createTextGroup({ material: glow });
three.material = glow; // the root's fallback
```

| Rule | Why |
| --- | --- |
| span → text → group → root precedence | the nearest material wins |
| equal factories share identity | the plan segments draws by material identity |
| return synchronously; never query or update text inside | it runs while three holds borrowed plan attributes |

{/* prose: `span` from `/three` accepts one material beside styles and a font; the root-level `material` is the
fallback for every text without one. */}
