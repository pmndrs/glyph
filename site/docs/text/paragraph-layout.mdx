## Constraints

```ts
type AxisConstraint =
  | { mode: 'unconstrained' }
  | { mode: 'at-most'; size: number }
  | { mode: 'exact'; size: number };
```

{/*
write
- Question: why is my centred paragraph not centred?
- Paragraph 1: `at-most` and `unconstrained` resolve to the content width — a short line shrinks to its text, so
  there is nothing to align within; `exact` preserves the stated box for alignment and columns. `height` bounds the
  block axis for `maxLines` and `overflow`.
- Paragraph 2: `measure()` reports both: `width`/`height` is the resolved box, `contentWidth`/`contentHeight` the

## Layout

<details>
<summary>ParagraphLayout members</summary>

| Property | Type | Notes |
| --- | --- | --- |
| `wrap` | `'none' \| 'word' \| 'character'` | UAX 14 word breaks, or any cluster |
| `align` | `'start' \| 'center' \| 'end' \| 'justify'` | logical start/end follow direction |
| `overflow` | `'visible' \| 'clip' \| 'ellipsis'` | what happens past `maxLines`/height |
| `maxLines` | `number` | line cap; positive integer |
| `firstLineIndent` | `number` | inline offset of the first line |
| `spaceBefore`, `spaceAfter` | `number` | block-axis spacing carried in measurement |
| `justify` | `{ minWordSpaceRatio?, maxWordSpaceRatio?, letterSpaceExpansion? }` | see below |
| `lastLine` | `'auto' \| 'justify'` | whether final and hard-broken lines justify |
| `columns` | `{ count, gap? }` | ordered columns inside an exact width; 1 to 16 |

</details>

```ts
import { Constraints, ParagraphLayout } from '@pmndrs/glyph';

const layouts = ParagraphLayout.create({
  editorial: { wrap: 'word', align: 'justify', columns: { count: 3, gap: 0.4 } },
  caption: { wrap: 'word', maxLines: 2, overflow: 'ellipsis' },
});
const boxes = Constraints.create({ column: { width: { mode: 'exact', size: 9 } } });

three.createText({ font: Inter, text: 'Editorial', layout: layouts.editorial, constraints: boxes.column });
```

## Justification bounds

```ts
three.createText({
  font: Inter,
  text: 'Justified',
  layout: {
    align: 'justify',
    justify: { minWordSpaceRatio: 0.85, maxWordSpaceRatio: 1.35, letterSpaceExpansion: 0.045 },
    lastLine: 'auto',
  },
  constraints: { width: { mode: 'exact', size: 6 } },
});
```

{/*
write
- Question: how do I stop justification from opening rivers?
- Paragraph 1: word spaces shrink to `minWordSpaceRatio` and grow to `maxWordSpaceRatio` as multiples of their
  natural advance; the remaining deficit spills into per-gap letter-space expansion up to `letterSpaceExpansion`;
  unset sides are unbounded, and a line that cannot fill within its bounds reads as under-full rather than
  stretched. Trailing spaces are trimmed before the deficit is measured.
- Paragraph 2: `lastLine: 'justify'` also justifies the final line and lines ending in a hard break; `'auto'` leaves
  them ragged. Distribution is euclidean in integer layout units, so fragment advances and cursor positions agree
  bit for bit.
- Shape: two paragraphs.

notes · internals
- bounds and validation — `text-properties.ts:59–70`, `:245–256` (`min` in `(0, 1]`, `max` ≥ 1, expansion ≥ 0)
- engine controls, zero = unbounded — `rust/shaper/src/engine/positioning.rs#JustifyControls` (`:1704–1713`)
- expansion: word spaces grow to the cap, remainder spills into inter-cluster gaps bounded per gap, residue stays
  unfilled — `rust/shaper/src/engine/positioning.rs:1827–1860`; compression never below the minimum — `:1873–1885`
- euclidean remainder in layout units — `rust/shaper/src/engine/positioning.rs:1730–1736`; D-254
- trailing spaces trimmed before distribution — `rust/shaper/src/engine/line_composition.rs:432–436`
- `lastLine` — `text-properties.ts:71–72`; `LAST_LINE_AUTO | LAST_LINE_JUSTIFY` — `rust/shaper/src/engine/frame.rs:60–61`
*/}

## Columns

{/*
write
- Question: can one paragraph flow through several columns?
- One paragraph: yes, inside an exact width: `columns: { count, gap }` splits the box into `count` ordered columns
  with `gap` between them in paragraph-local units; text fills each column in order without balancing, so the last
  may run short. More than one column without an exact width throws at the boundary. The landing page's chorus is a
  three-column justified paragraph.
- Shape: one paragraph.

## Overflow and ellipsis

{/*
write
- Question: what happens to text that does not fit?
- One paragraph: `clip` cuts at the box; `ellipsis` replaces the tail of the last permitted line, shaping the
  ellipsis through the same fonts as the text; `visible` lets lines run past the box and sets
  `measure().overflowed` so you can react. `maxLines` and `height` both decide where "past" is.
- Shape: one paragraph.
