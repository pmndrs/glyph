```ts
import { Matrix4 } from 'three/webgpu';

const [glyphs, decorations] = text.breakApart();
text.parent!.add(glyphs);                        // sibling attachment overlays the source exactly
if (decorations !== undefined) text.parent!.add(decorations);
text.visible = false;

const m = new Matrix4();
glyphs.getMatrixAt(3, m);
m.setPosition(0, 0.4, 0);
glyphs.setMatrixAt(3, m);

glyphs.materials[0]!.opacity = 0.65;             // a clone; the source is untouched

glyphs.dispose();
decorations?.dispose();
text.visible = true;
```

## Glyphs

| Member | Meaning |
| --- | --- |
| `count` | drawable detached glyphs; spaces and other record-less glyphs are left out |
| `glyphAt(index)` | `DetachedGlyph`: `index`, `sourceIndex`, `key`, `cluster`, `line`, `word`, `fontSize`, `advance` |
| `getMatrixAt` / `setMatrixAt` | full affine matrix in `Glyphs`-local space |
| `getWorldMatrixAt` / `setWorldMatrixAt` | the same through the root's world transform; updates and inverts the ancestor chain every call |
| `measurements` | `ThreeGlyphMeasurement[]`, original transforms and bounds |
| `materials` | cloned material instances owned by this branch |
| `dispose()` | releases plan, storage, materials, leases; removes it from its parent |

{/*
write
- Question: what does the object look like?
- Paragraph 1: it follows `InstancedMesh`: a dense index from 0 to `count`, a full affine matrix per index, read
  and written in the object's local space, with world-space variants for one-off writes. The root starts with the
  source's local transform, and each record starts at its committed drawn origin, so adding it beside the source
  overlays it exactly.
- Paragraph 2: `glyphAt` gives identity and grouping — cluster, line, word — so a stagger by word or by line needs no
  segmentation of your own. `key` survives a reflow that moves glyphs and not one that reshapes them.
- Shape: two paragraphs; the table is the reference.

## Measurements

```ts
const [glyphs] = text.breakApart();
const m = glyphs.measurements[0]!;
m.originalMatrix;                                // where it was, in the source Text's local space
m.localInkBounds;                                // Box3
m.localAdvanceBounds;                            // Box3
m.anchorPoint({ x: 'center', y: 'min' }, 'ink'); // Vector3
m.geometry;                                      // metric quad or the technique's supplied mesh, with bounds
```

## Text on a circle

```ts
import { Matrix4, Quaternion, Vector3 } from 'three/webgpu';

const radius = text.measure().contentWidth / (Math.PI * 2); // advance extent, not the resolved box width
const [glyphs] = text.breakApart();
const m = new Matrix4();
const home = new Vector3();
const q = new Quaternion();
const s = new Vector3();
const turn = new Quaternion();
const up = new Vector3(0, 1, 0);
for (let i = 0; i < glyphs.count; i += 1) {
  const rest = glyphs.measurements[i];
  if (rest === undefined) continue;
  rest.originalMatrix.decompose(home, q, s);
  const angle = home.x / radius;                     // advance along the line → angle
  turn.setFromAxisAngle(up, angle);
  m.compose(new Vector3(Math.sin(angle) * radius, home.y, Math.cos(angle) * radius), turn.multiply(q), s);
  glyphs.setMatrixAt(i, m);
}
```

## World-space writes in bulk

```ts
import { worldToLocalMatrix } from '@pmndrs/glyph/three';
import { Matrix4 } from 'three/webgpu';

const [glyphs] = text.breakApart();
const bodies: Matrix4[] = []; // one world matrix per glyph, from your physics step
const scratch = new Matrix4();

glyphs.updateMatrixWorld();
const inverse = glyphs.matrixWorld.clone().invert();
for (let i = 0; i < glyphs.count; i += 1) {
  worldToLocalMatrix(inverse, bodies[i]!, scratch);
  glyphs.setMatrixAt(i, scratch);
}
```

{/*
write
- Question: physics gives me world matrices; what is the cheap way in?
- Paragraph 1: update the root once, invert its `matrixWorld` once, convert each body's world matrix through
  `worldToLocalMatrix`, and write with `setMatrixAt`. `setWorldMatrixAt` is correct for a one-off but updates and
  inverts the ancestor chain on every call.
- Paragraph 2: first-frame and same-render writes upload before the draw on both backends, so a matrix written in
  the `useFrame` right after attachment is what that frame shows.
- Shape: two paragraphs.

notes · internals
- `worldToLocalMatrix(inverse, world, target)`, target may alias — `three/glyphs.ts:18–33`; `localToWorldMatrix` — `:35–49`
- the bulk recommendation — `three/glyphs.ts:267–273` (docstring), `.agents/docs/planning/three-api.md:390–393`
- writes mark storage and the WebGL2 PBO mirror; uploaded before draw on WebGPU and WebGL2 — `.agents/docs/planning/detached-glyph-slice.md:101`; D-292

## Ownership

| Fact | Consequence |
| --- | --- |
| the source stays live | later source publications never touch the copy |
| copies lease atlas and page resources | no re-upload; the source `Text` and its `FontFace` may be disposed first |
| the caller owns attachment, visibility, physics, reset, disposal | nothing happens automatically |
| materials are cloned | changing one cannot affect the source or a sibling branch |
