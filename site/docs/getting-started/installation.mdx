<Intro>
  One package, many entry points. Import only the subpaths your application uses: each raster format, the React
  layer, the shader realizations, and the bakers are separate graphs, so a bundle carries only what it renders.
</Intro>

```bash
npm install three @react-three/fiber @pmndrs/glyph
```

{/* prose: peers — three 0.185, @react-three/fiber v10 (WebGPU entry), React 19. */}

## Entry points

<details>
<summary>Every subpath and what it pulls into a bundle</summary>

| Subpath | Exports | Pulls in |
| --- | --- | --- |
| `@pmndrs/glyph` | `glyph`, `loadFont`, `createFontStack`, `createParagraph`, `TextStyle`, `ParagraphLayout`, `Constraints`, `txt`, `span`, `defineFont`, `defineGlyphConfig` | the shaper Wasm, on first use |
| `@pmndrs/glyph/three` | `ThreeConfig`, `defineThreeConfig`, `Text`, `TextGroup`, `ThreeRoot`, `span`, `defineTextMaterial`, `Glyphs`, `Decorations`, `FontLoader`, `TextFrameError` | three.js and all three built-in formats |
| `@pmndrs/glyph/three/bitmap` · `/msdf` · `/slug` | the format value (`bitmap`, `msdf`, `slug`) plus its options | that format's decoder and Three program |
| `@pmndrs/glyph/react` | `GlyphProvider`, `Text`, `TextGroup`, `useFont` | React Three Fiber |
| `@pmndrs/glyph/react/bitmap` · `/msdf` · `/slug` | `useBitmap`, `useMsdf`, `useSlug` | that format |
| `@pmndrs/glyph/raster/*` | renderer-neutral format contracts | no renderer |
| `@pmndrs/glyph/tsl` · `/tsl/{bitmap,msdf,slug,decoration}` | TSL shader realizations | no scene integration |
| `@pmndrs/glyph/typegpu` · `/typegpu/bitmap` | TypeGPU shader realizations | no scene integration |
| `@pmndrs/glyph/bake` · `/baker` · `/bakers/*` | Node baking, the baker host, portable raster bakers | the baker Wasm, validator |
| `@pmndrs/glyph/runtime-bake` | `bakeFontInWorker` | a module Worker, on demand |
| `@pmndrs/glyph/*.wasm` | `text-shaper`, `font-baker`, `bitmap-baker`, `mtsdf-baker`, `slug-baker` | distribution artifacts |

</details>

{/* prose: the root entry has no static edge to the baker, validator, or any Wasm beyond the shaper; importing a
format module registers it; `/three` imports all three formats so ordinary Three apps need no extra import. */}

## Renderer entry

```tsx
import { Canvas } from '@react-three/fiber/webgpu';
```

{/* prose: the WebGPU entry is the maintained target; three's `WebGPURenderer` constructs a WebGL2 backend when
`navigator.gpu` is missing — no configuration needed. */}

> [!NOTE]
> `navigator.gpu` exists only in a secure context. On `http://<lan-ip>` you get WebGL2, not a broken page; on
> `https://` or `localhost` you get WebGPU. Wasm loads on any origin.

## Serving

> [!WARNING]
> Serve from `localhost` or over `https`. Every font load hashes the artifact with `crypto.subtle`, which browsers
> expose only in a secure context, so a page opened at `http://10.0.0.62` fails to load fonts. WebGPU is gated the
> same way; three's WebGL2 fallback is not, so a scene without text still draws while the text does not. The
> baked `.font.glb` files are static assets: any host that serves them with a correct `Content-Length` works, and
> `Cache-Control` on a source font decides how long a runtime bake is kept.
