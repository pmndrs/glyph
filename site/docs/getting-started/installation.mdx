Install `@pmndrs/glyph` with the renderer you use. Every renderer is an optional peer dependency, so you install only
what you import.

```sh
npm install @pmndrs/glyph three
```

## Peers by renderer

| You render with | Also install | Supported range |
| --- | --- | --- |
| three.js | `three` | `>=0.185.0` |
| React Three Fiber | `three`, `react`, `@react-three/fiber` | React `>=19.0.0 <19.3`; Fiber `>=9.7.0 <10` or `>=10.0.0-alpha.4 <11` |
| Vue with TresJS | `three`, `vue`, `@tresjs/core` | Vue `>=3.5 <4`; TresJS `>=5.8.3 <6` |
| TypeGPU | `typegpu` | `>=0.12.5 <0.13` |
| three.js with TypeGPU shaders | `three`, `typegpu`, `@typegpu/three`, `@typegpu/gl` | `@typegpu/three` `>=0.12.1 <0.13`; `@typegpu/gl` `>=0.12.4 <0.13` |
| PixiJS 3D | `pixi.js`, `@pixi/3d` | `pixi.js` `>=8.23.0 <9`; `@pixi/3d` `>=0.1.0 <0.2` |

The package is ESM only.

## WebGPU and the React Three Fiber entry

The three.js integration is written for `WebGPURenderer`. In React Three Fiber, import the canvas from the WebGPU
entry:

```tsx
import { Canvas } from '@react-three/fiber/webgpu';
```

Browsers expose WebGPU only in a secure context: `https://` or `http://localhost`. On another origin, such as a LAN
address over plain HTTP, `navigator.gpu` is absent and three.js falls back to its WebGL 2 backend.

## Font files in a bundler

A baked font is a `.font.glb` file that you serve as a static asset. With Vite, import its URL:

```ts
import interUrl from './fonts/inter.font.glb?url';
import { glyph, msdf } from '@pmndrs/glyph';

const Inter = glyph.fontFace(interUrl, { format: msdf });
```

## TypeScript

Fonts and texts carry their raster format in their type, so a material or an option that only one format supports is
checked at compile time.

```ts
import type { Font, FontFace } from '@pmndrs/glyph';
import type { msdf } from '@pmndrs/glyph';
import type { slug } from '@pmndrs/glyph';

let body: Font<typeof msdf>;
let face: FontFace<typeof msdf | typeof slug>;
```

See [TypeScript](/guides/project/typescript) for the patterns.
