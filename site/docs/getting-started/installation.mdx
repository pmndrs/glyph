<Intro>
  One package, many entry points. Import only the subpaths your application uses: each raster technique, the React
  layer, the baker, and the integrator core are separate graphs, so a bundle carries only what it renders.
</Intro>

```bash
npm install three @react-three/fiber @pmndrs/glyph
```

{/* prose: peers — three (0.185+), @react-three/fiber (WebGPU entry, v10), React 19. */}

## Entry points

<details>
<summary>Every subpath and what it pulls into a bundle</summary>

| Subpath | Exports | Pulls in |
| --- | --- | --- |
| `@pmndrs/glyph` | `glyph`, `loadFont`, `createFontStack`, `createParagraph`, `TextStyle`, `ParagraphLayout`, `Constraints`, `txt`, `span`, `defineFont` | the shaper Wasm, on first use |
| `@pmndrs/glyph/three` | `ThreeConfig`, `defineThreeConfig`, `Text`, `TextGroup`, `defineTextMaterial`, `Glyphs`, `Decorations`, `FontLoader`, `TextFrameError` | three.js |
| `@pmndrs/glyph/three/bitmap` · `/msdf` · `/slug` | the technique value (`bitmap`, `msdf`, `slug`) | that technique's decoder and TSL program |
| `@pmndrs/glyph/react` | `GlyphProvider`, `Text`, `TextGroup`, `useFont` | React Three Fiber |
| `@pmndrs/glyph/react/bitmap` · `/msdf` · `/slug` | `useBitmapFont`, `useMSDF`, `useSlug` | that technique |
| `@pmndrs/glyph/raster/*` | renderer-neutral technique contracts | no renderer |
| `@pmndrs/glyph/bake` | `bakeFont`, `bakeProject` (Node) | the baker Wasm, validator |
| `@pmndrs/glyph/runtime-bake` | `bakeFontInWorker` | a module Worker, on demand |
| `@pmndrs/glyph/core` | `GlyphConfig`, `createGlyphEngine`, plan readers | integrator machinery |
| `@pmndrs/glyph/tsl` · `/typegpu` | technique shader realizations | no scene integration |
| `@pmndrs/glyph/bakers/*` | portable raster bakers | optional |
| `@pmndrs/glyph/*.wasm` | `text-shaper`, `font-baker`, `bitmap-baker`, `mtsdf-baker`, `slug-baker` | distribution artifacts |

</details>

{/* prose: the root entry has no static edge to the baker, validator, or any Wasm beyond the shaper; importing a
technique module registers it. */}

## Renderer entry

```tsx
import { Canvas } from '@react-three/fiber/webgpu';
```

{/* prose: the WebGPU entry is the maintained target. three's `WebGPURenderer` constructs a WebGL2 backend when
`navigator.gpu` is missing — no configuration needed. */}

> [!NOTE]
> `navigator.gpu` exists only in a secure context. On `http://<lan-ip>` you get WebGL2, not a broken page; on
> `https://` or `localhost` you get WebGPU. Wasm loads on any origin.
