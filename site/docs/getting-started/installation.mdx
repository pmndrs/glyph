## Serving

| Origin | `navigator.gpu` | `crypto.subtle` | What you get |
| --- | --- | --- | --- |
| `https://…`, `http://localhost` | present | present | WebGPU; fonts load |
| `http://<lan-ip>`, `http://<hostname>` | absent | absent | WebGL2 backend; every font load rejects |

{/*
write
- Question: why does my LAN address draw the scene but no text?
- Open with an `> [!WARNING]`: serve from `localhost` or over `https`. Every font load hashes the artifact with
  `crypto.subtle`, which browsers expose only in a secure context, so a page opened at a plain LAN address fails to
  load fonts while three's WebGL2 fallback still draws the rest of the scene. The baked `.font.glb` files are static
  assets: any host that serves them with a correct `Content-Length` works, and `Cache-Control` on a source font
  decides how long a runtime bake is kept.
- Shape: the callout, four sentences; the table carries the matrix.

notes · internals
- every load hashes bytes with `crypto.subtle.digest('SHA-256', …)`: the main GLB — `loader.ts:3125`; raster
  artifacts — `internal/raster-artifact-validation.ts:380`; the raster key — `internal/raster-identity.ts:102`;
  transfers — `internal/font-face-transfer-runtime.ts:167`; runtime-bake cache — `internal/runtime-font-cache.ts:125`
- [verify] that `crypto.subtle` is undefined on an insecure origin (WebCrypto `[SecureContext]`); the tree only shows
  the calls, not the gate
- `content-length` is read and compared — `loader.ts:2813`; `cache-control` decides how long a runtime bake is kept —
  `loader.ts:2734`
- baked `.font.glb` files are static assets; the docs serve them from `site/docs/assets/*.font.glb`
*/}

## TypeScript

```ts
import type { Font, FontFace } from '@pmndrs/glyph';
import type { msdf } from '@pmndrs/glyph/raster/msdf';
import type { slug } from '@pmndrs/glyph/raster/slug';

let body: Font<typeof msdf>;
let face: FontFace<typeof msdf | typeof slug>;
```

{/*
write
- Question: what does the type system give me for free?
- Say: `exactOptionalPropertyTypes` is respected. The format generic is inferred from the face you declare: a face
  declared with `msdf` and `slug` has exactly `.msdf` and `.slug`, and `.bitmap` is a compile error; `createText`
  and `<Text>` carry that format into the `Text` they return.
- Shape: two sentences; link Advanced → TypeScript.

notes · internals
- the package compiles with `exactOptionalPropertyTypes` — `tsconfig.base.json:6`
- `glyph.fontFace` is `const`-generic over the declaration; the keyed members are synthesized from it, so an
  undeclared member fails at compile time — `glyph.ts:24–27`, `font-face.ts:35–39` (`FontFaceDeclaredFormat`),
  `:95–97` (`FontFace`); D-310
- `createText` infers the raster from the selection — `three/text.ts:257–259`; R3F `Text` infers it from `font` —
  `react.ts:431–438` (`TextComponent`)
- `Font<Format>` and `FontFace<Formats>` are root types — `index.ts:201`, `:181`
