## 1. Bake the font

```bash
npx glyph bake --input Inter-Regular.ttf --output public/fonts/inter.font.glb --msdf
```

{/*
write
- Question: what does baking produce, and when do I run it?
- Say: the GLB carries the font's shaping data and an MSDF atlas at the defaults, 64 texels per em with an 8-pixel
  range; nothing in it is platform-specific; run it once at build time and commit the output. Point at Baking fonts
  for the other formats and for subsets.
- Shape: two sentences.

notes · internals
- the CLI usage text — `packages/glyph/src/node/cli.ts:532–573`; `--input` accepts TTF, OTF, TTC, OTC (`:542`);
  `--output` is a GLB with shaping data plus the selected rasters (`:543`)
- bare `--msdf` means the defaults — `cli.ts:295–300`; the defaults are `emSize` 64, `pixelRange` 8 —
  `internal/msdf-contract.ts:10–11`
- the packaged executable — `package.json` bin, `packages/glyph/bin/glyph.js`
*/}

## 2. Load it

```tsx
import { useMsdf } from '@pmndrs/glyph/react/msdf';

const inter = useMsdf('/fonts/inter.font.glb');
```

{/*
write
- Question: what did that one line do?
- Say: the hook declared a face for that URL on the handle your canvas uses, started the load, suspended the
  component until the MSDF raster was ready, and returned a loaded font that stays alive while the component is
  mounted. Call it again anywhere with the same URL and you get the same face.
- Shape: two sentences; the string is the baked URL, nothing more to explain here.

notes · internals
- `useMsdf(url, options?)` builds the MSDF request and delegates — `react/msdf.ts:7–13`, `:16–17`
- the hook declares a `FontFace` through `glyph.fontFace` on the selected handle, cached per handle by source and
  format — `react.ts#useFont` (`:628–631`), `:667–683` (`reactFontFaceResource`), `font-face.ts:303–305`
  (`fontFaceResourceKey`)

## 5. Wrap it

```tsx
import { Text } from '@pmndrs/glyph/react';

<Text
  font={inter}
  style={{ fontSize: 0.6, color: '#ffd166' }}
  layout={{ wrap: 'word', align: 'center' }}
  constraints={{ width: { mode: 'at-most', size: 6 } }}
>
  The quick brown fox jumps over the lazy dog
</Text>;
```

{/*
write
- Question: why three props and not one?
- Say: they are orthogonal. `style` is inherited by the runs inside the paragraph; `layout` is the flow policy of
  the paragraph itself; `constraints` is the box a parent imposes, and would change if the parent did. `at-most`
  lets a short line shrink to its content; `exact` keeps the box, which is what you centre inside.
- Shape: two sentences; the enumerations live in the notes and on Paragraph layout.

notes · internals
- `ParagraphLayout`: `maxLines`, `wrap` (`none | word | character`), `align` (`start | center | end | justify`),
  `overflow`, `firstLineIndent`, `spaceBefore`, `spaceAfter`, `justify`, `lastLine`, `columns` —
  `text-properties.ts:48–80`
- `Constraints`: `width` and `height`, each `unconstrained`, `at-most`, or `exact` — `text-properties.ts:36–45`
- `layout` and `constraints` belong to the outer Text only — `react.ts:87–90`
- every prop is a `PropertyList`: a value, `false`, `null`, or a nested array, merged in order —
  `text-properties.ts:33`; `ParagraphLayout.create`, `Constraints.create` — `:149–156`
*/}

## 6. Measure it

```tsx
import { useRef } from 'react';
import { useFrame } from '@react-three/fiber/webgpu';
import { Text } from '@pmndrs/glyph/react';
import type { Text as ThreeText } from '@pmndrs/glyph/three';
import type { msdf } from '@pmndrs/glyph/raster/msdf';

function Centered() {
  const ref = useRef<ThreeText<typeof msdf>>(null);
  useFrame(() => {
    const ink = ref.current?.measure().inkBounds;
    if (ink) ref.current!.position.set(-(ink.x + ink.width / 2), ink.y + ink.height / 2, 0);
  });
  return (
    <Text ref={ref} font={inter} layout={{ wrap: 'word', align: 'center' }} constraints={{ width: { mode: 'at-most', size: 6 } }}>
      The quick brown fox jumps over the lazy dog
    </Text>
  );
}
```

{/*
write
- Question: how do I centre it?
- Say: `measure()` answers synchronously for the state you set, before the first frame commits. `inkBounds` is what
  was drawn and `contentWidth`/`contentHeight` are what layout reserved; centre on ink, because a script face with
  swashes overhangs its advance. The `useFrame` is there because the ref is assigned after the object is committed;
  a layout effect in the same component runs too early.
- Shape: three sentences; link Measurement.

notes · internals
- `measure()` answers for desired state, synchronously, before the first frame commits — `three/text.ts:732–742`
- `inkBounds` is the union of glyph ink; `contentWidth`/`contentHeight` are advance extents; `undefined` means
  "not measured", never "empty" — `layout.ts:56–61`, `:73–75`, `:80–89`
- the `ref` is the three.js `Text` — `react.ts:95`, assigned after the object is published — `:451–452`
- the same centering, in the running example — `site/examples/src/scenes/first-text/scene.tsx:19–26`
- the sign of `ink.y`: paragraph space is y-down from the box's top-left (`glyph-placement.ts:4–14`, `GlyphSpace`),
  `LayoutBox` is `{ x, y, width, height }` in that space (`layout.ts:8–13`), and the measurement scene draws the ink
  box at `-(y + height / 2)` in three's y-up space and lands on the glyphs
  (`site/examples/src/scenes/measurement/scene.tsx`, `Outline`)
- `computeBoundingBox()` is the `Box3` alternative — `three/text.ts:766–769`
*/}

## 7. The same in plain three.js

```ts
import { glyph } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';

await glyph.init();
const handle = glyph.handle('app', ThreeConfig);
const Inter = glyph.fontFace('/fonts/inter.font.glb');
await Inter.load();

const label = handle.createText({
  font: Inter,
  text: 'The quick brown fox jumps over the lazy dog',
  style: { fontSize: 0.6, color: '#ffd166' },
  layout: { wrap: 'word', align: 'center' },
  constraints: { width: { mode: 'at-most', size: 6 } },
});
scene.add(label);

const ink = label.measure().inkBounds;
if (ink) label.position.set(-(ink.x + ink.width / 2), ink.y + ink.height / 2, 0);

glyph.shape();
renderer.render(scene, camera);
```

- Question: what did R3F do for me?
- Say: it called `glyph.init()`, made the default handle, and ran `glyph.shape()` inside every render; vanilla names
  those three and is otherwise identical — the same face, the same `createText` properties, the same `measure()`.
- Shape: two sentences.

notes · internals
- what R3F did for you: `glyph.init()` and the default handle — `react.ts:376–407`; a root per R3F store —
  `:268–278`; `shape()` from the draw root's `updateMatrixWorld` inside `renderer.render` — `three/text.ts:139–142`,
  `:478–486`
- `glyph.fontFace(url)` with no `format` resolves to the handle's default, MSDF — `three/handle.ts:177`; D-297
- `createText` binds the face's loaded MSDF `Font` into the Text — `three/text.ts:266–277`
- the maintained imperative proof — `apps/r3f-hello-world/src/three-example.ts:17–57`
