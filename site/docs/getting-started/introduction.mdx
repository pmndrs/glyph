<Intro>
  `@pmndrs/glyph` shapes and lays out text in Rust/Wasm, then publishes a retained render plan for the active renderer.
  The maintained Three.js integration supports Bitmap, MSDF, and Slug through WebGPU and Three's WebGL fallback.
</Intro>

## Install

```sh
npm install @pmndrs/glyph
```

## Render text with React Three Fiber

```tsx
import { Text, TextGroup, useFont } from '@pmndrs/glyph/react';
import { msdf } from '@pmndrs/glyph/three/msdf';

const fontRequest = {
  input: { baked: '/fonts/Inter.font.glb' },
  technique: msdf,
} as const;

useFont.preload(fontRequest.input, fontRequest.technique);

function Labels() {
  const inter = useFont(fontRequest.input, fontRequest.technique);

  return (
    <TextGroup compositing="independent">
      <Text
        font={inter}
        constraints={{ width: { mode: 'at-most', size: 480 } }}
        layout={{ wrap: 'word' }}
        style={{ color: '#f4f7ff', fontSize: 32, lineHeight: 1.2 }}
      >
        Hello <Text style={{ color: '#70d6ff' }}>world</Text>
      </Text>
    </TextGroup>
  );
}
```

`Text` is a retained paragraph and a Three `Object3D`. A nested `Text` is a span, and inherits the surrounding
font, style, paint, and material unless it overrides them.

`TextGroup` is an optional batching and ordering boundary. It collects descendant `Text` objects through the
ordinary scene graph, so regular Three groups may appear between them. A standalone `Text` has the same text
semantics and lazily owns an implicit batch of one.

## An inline scene proxy

The docs page can host a Three scene without making the docs application an R3F application. The root is a custom
element that owns a bounded pool of R3F roots and offscreen surfaces on one shared GPU device; each proxy is an ordinary page
element that receives copied frames. Proxies can be placed anywhere in the MDX document and bind to the root by id.

Both targets may be visible together: the controller leases one pooled offscreen root to each visible proxy, then
recycles idle roots after the TTL. Scroll to move them in and out of the pool. Click either proxy to send a targeted
pointerdown through the root's ordered page-local stream and change only that scene's word color. Pointer motion is
coalesced to one update per 30 ms; clicks, keys, controls, and scene changes flush immediately in occurrence order.

<glyph-proxy

The component is just HTML from the MDX compiler. Its JavaScript class is registered with
`customElements.define`, so this remains compatible with the React components supplied by `pmndrs/docs` while
keeping the WebGPU renderer, font cache, and animation loop outside the docs React tree.

### Break apart and pulse

Click the explainer to create two detached `Glyphs` branches: a Geist MSDF title and a tight VT323 bitmap copy block.
Every glyph gets its own sleeping Box3D body, so a click wakes only the nearby glyphs and leaves the rest floating in
place. Reset disposes the branches and makes the live `Text` objects visible again. Physics remains application-owned;
`Glyphs.measurements` is the data a physics adapter can use to choose its own body shapes.

<glyph-proxy
  id="introduction-physics-proxy"
  height="24rem"
  root="introduction-glyph-scene"
  data-scene="physics"
  role="button"
  aria-label="Glyph break-apart impulse and reset demo"
/>
<glyph-scene-control
  root="introduction-glyph-scene"
  proxy="introduction-physics-proxy"
  data-action="reset"
>
Reset physics
</glyph-scene-control>

This example uses Isaac Mason's `box3d.js` WebAssembly bindings to create one sleeping rigid body per
detached glyph and a six-sided boundary aligned to the proxy viewport. The physics adapter chooses
box bodies from each glyph's `localInkBounds` transformed by the detached root's `matrixWorld`, applies a gentle
world-space radial impulse from the click point, then hoists one inverse per detached root and writes each Box3D world
transform through `worldToLocalMatrix()` and `Glyphs.setMatrixAt()`;
the glyph package does not own the physics world. `box3d.js` and the Box3D engine are MIT licensed;
their license notices remain in the installed package.

## Bake a font

Fonts are baked ahead of time into a `.font.glb` carrying the shaping data and every raster you ask for.

```sh
npx glyph bake --input Inter-Regular.ttf --output inter.font.glb \
  --unicodes U+0020-007E --bitmap 32 --msdf --slug
```

`--unicodes` subsets the shaping font, so an artifact only carries the coverage you render.
