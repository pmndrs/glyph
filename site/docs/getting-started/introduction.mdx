<Intro>
  `@pmndrs/glyph` retains authored text, shapes and lays it out in Rust/Wasm, then publishes a transient render plan
  for the active renderer. The maintained three.js integration supports Bitmap, MSDF, and Slug through WebGPU and
  three's WebGL fallback.
</Intro>

```bash
npm install three @react-three/fiber @pmndrs/glyph
```

## Render text with React Three Fiber

```tsx
import { Text, TextGroup } from '@pmndrs/glyph/react';
import { useBitmap } from '@pmndrs/glyph/react/bitmap';
import { useMsdf } from '@pmndrs/glyph/react/msdf';
import { useSlug } from '@pmndrs/glyph/react/slug';

const VT323 = '/fonts/VT323.font.glb';
const INTER = '/fonts/Inter.font.glb';
const LOVERS_QUARREL = '/fonts/LoversQuarrel.font.glb';

void useMsdf.preload(INTER);

function Labels() {
  const inter = useMsdf(INTER);
  const loversQuarrel = useSlug(LOVERS_QUARREL);
  const vt323 = useBitmap(VT323, { strikes: [8, 16] });

  return (
    <>
      <Text
        font={loversQuarrel}
        style={{ fontSize: 32, color: '#f7f7f7' }}
        layout={{ align: 'center' }}
        constraints={{ width: { mode: 'exact', size: 480 } }}
        position={[0, -4, 0]}
      >
        Lorem <Text style={{ color: '#f70000' }}>Ipsum</Text>
      </Text>
      <TextGroup>
        <Text
          font={inter}
          style={{ fontSize: 32, color: '#f7f7f7' }}
          layout={{ align: 'center' }}
          constraints={{ width: { mode: 'exact', size: 480 } }}
          position={[0, -1, 0]}
        >
          Eos tempor iusto mollit reprehenderit dolor cillum.
        </Text>
      </TextGroup>
      <Text
        font={vt323}
        style={{ fontSize: 8, color: '#f7f7f7' }}
        layout={{ wrap: 'word' }}
        constraints={{ width: { mode: 'at-most', size: 480 } }}
        position={[0, 0, 0]}
      >
        lorem ipsum dolor sit amet consectetur adipiscing elit eiusmod anim vel proident nam sint quo laborum
      </Text>
    </>
  );
}
```

{/* prose (from the README): an outer Text is a retained paragraph and a Three Object3D; a nested Text is an inline
run that inherits font, style, and material and creates no scene object; TextGroup is a scene-hierarchy parent. Three
fonts, three raster formats, one component. */}

## Render text with three.js

```ts
import { glyph, span, txt } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';

await glyph.init();
const three = glyph.handle('main', ThreeConfig);
const interFace = glyph.fontFace({ baked: '/fonts/Inter.font.glb' });
await interFace.load();

const accent = span({ color: '#70d6ff' });
const label = three.createText({
  font: interFace,
  text: txt`Hello ${accent`world`}`,
  style: { fontSize: 32, lineHeight: 1.2, color: '#f4f7ff' },
  layout: { wrap: 'word' },
  constraints: { width: { mode: 'at-most', size: 480 } },
});

scene.add(label);
glyph.shape();                  // publish every dirty root; Mesh children now sit below label
renderer.render(scene, camera); // three performs the actual draw
```

{/* prose (from the README): the root `glyph` is the runtime — `init()` once, a named handle per adapter, a FontFace
declared once and loaded once; `createText` returns an ordinary Object3D, not a canvas or renderer; `shape()` attaches
planned meshes; `renderer.render` draws them. Three uses `txt`/`span` where React uses nested Text. */}

## Measure before you render

```ts
scene.add(label);
const measured = label.measure();
label.position.x = -measured.contentWidth / 2;
glyph.shape();
renderer.render(scene, camera);
```

{/* prose: measurement needs no world matrix, renderer resource, or committed frame; `Paragraph` measures with no
scene object at all. Link Measurement. */}

## Does it need WebGPU?

{/* prose: no — `WebGPURenderer` carries a WebGL2 backend and falls back on its own when `navigator.gpu` is absent
(which it is on any plain-http origin). Every format renders on both. */}

## Is it slower than sprites or a canvas texture?

{/* prose: no — text is instanced, batched, and retained. Every Text on a root shares one planner; the plan emits only
the draw boundaries a format, resource, material, clip, or compositing policy requires. Point at Performance. */}

## Which scripts and languages?

{/* prose: HarfRust shaping with pinned HarfBuzz as the oracle; Latin, Arabic joining, Indic reordering, mixed bidi,
CJK line breaking; Unicode 17 segmentation and line breaking in JS. Horizontal layout; vertical is a later milestone.
Link the shaping example. */}

## Can I use my own shader?

{/* prose: yes — `defineTextMaterial` hands you the format's TSL coverage/color nodes and takes back any NodeMaterial,
lit PBR included. Link Materials. */}

## Where does layout happen?

{/* prose: Rust, in integer F26.6 units under one rounding contract; JavaScript owns Unicode analysis and the render
