<Intro>
  `@pmndrs/glyph` is a typography engine for web graphics. It bakes fonts ahead of time, shapes and lays out text in a
  Rust/Wasm engine, and draws it as batched GPU text in three.js, React Three Fiber, Vue with TresJS, TypeGPU and
  PixiJS 3D.
</Intro>

## What it does

- **Real shaping.** Text is shaped by a HarfBuzz-compatible shaper, so ligatures, kerning, complex scripts and
  right-to-left text come out as the font intends. See [Languages and scripts](/guides/text/languages-and-scripts)
  and [Bidirectional text](/guides/text/bidirectional-text).
- **Paragraph layout.** Wrapping, alignment, justification, truncation, columns, text that flows through regions and
  around shapes, and drop caps. Start at [Size a paragraph](/guides/layout/size-a-paragraph).
- **Three raster formats.** Bitmap, MSDF and Slug, chosen per font at load.
  [Raster formats](/explanation/formats) explains the trade-offs.
- **Rich text.** Spans with their own style, font and material inside one paragraph. See
  [Rich text](/guides/text/rich-text).
- **Measurement and inspection.** Paragraph and line metrics, per-glyph data and outlines, available before the
  frame that draws them. See [Measure text](/guides/inspect/measure-text).
- **Editing geometry.** Hit testing, carets, selection rectangles, movement by grapheme, word and line, and exact
  edits. Build a field in [An editable text field](/tutorials/editable-text-field).
- **Scene integration.** Text is a scene object: it takes transforms, depth, custom materials, post-processing and
  frustum culling, and compatible draws batch. See [Place text in 3D](/guides/scene/place-text-in-3d).
- **Per-glyph animation.** A laid-out paragraph can be split into glyphs you move yourself. See
  [Animate glyphs](/guides/scene/animate-glyphs).

## About the live demos

Every demo on this site is a real scene, not a video. A page has one renderer and one GPU device however many demos
it shows. A demo shows a still image until its scene has loaded, runs while it is on screen, and holds its last frame
when you scroll past it. Demos that take input say so in the sentence below them.
