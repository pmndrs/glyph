<Intro>
  `@pmndrs/glyph` shapes and lays out text in Rust/Wasm, publishes a retained render plan, and lets three.js draw it.
  One baked font file carries the shaping data plus any of three raster techniques — Bitmap, MSDF, and Slug — and the
  same `Text` object works from React Three Fiber or plain three.js, on WebGPU with three's own WebGL2 fallback.
</Intro>

```bash
npm install three @react-three/fiber @pmndrs/glyph
```

## What does it look like?

{/* prose: one sentence framing the example — a font, a Text, nothing else. */}

```tsx
import { Canvas } from '@react-three/fiber/webgpu';
import { Text } from '@pmndrs/glyph/react';
import { useMSDF } from '@pmndrs/glyph/react/msdf';

function Hello() {
  const inter = useMSDF({ baked: '/fonts/inter.font.glb' });
  return (
    <Text font={inter} style={{ fontSize: 1, color: '#f4f7ff' }}>
      Hello world
    </Text>
  );
}

export default function App() {
  return (
    <Canvas>
      <Hello />
    </Canvas>
  );
}
```

The same text from plain three.js, without React:

```ts
import { glyph, loadFont } from '@pmndrs/glyph';
import { ThreeConfig } from '@pmndrs/glyph/three';
import { msdf } from '@pmndrs/glyph/three/msdf';

await glyph.init();
const three = glyph.handle('main', ThreeConfig);
const inter = await loadFont({ baked: '/fonts/inter.font.glb' }, msdf);

const label = three.createText({ font: inter, text: 'Hello world', style: { fontSize: 1 } });
scene.add(label);
```

## Does it need WebGPU?

{/* prose: no. `WebGPURenderer` carries a WebGL2 backend and falls back on its own when `navigator.gpu` is absent
(which it is on any plain-http origin). Every technique renders on both. */}

## Is it slower than sprites or a canvas texture?

{/* prose: no — text is instanced, batched, and retained. One `TextGroup` becomes one planner; compatible glyphs share
buffers and the plan emits only the draw boundaries a technique, resource, material, clip, or compositing policy
actually requires. Point at Performance for the numbers. */}

## Which scripts and languages?

{/* prose: HarfRust shaping with pinned HarfBuzz as the oracle; Latin, Arabic joining, Indic reordering, mixed bidi,
CJK line breaking; Unicode 17 segmentation and line breaking in JS. Horizontal layout; vertical is a later milestone.
Link the shaping example. */}

## Can I use my own shader?

{/* prose: yes — `defineTextMaterial` hands you the technique's TSL coverage/color nodes and you return any
NodeMaterial, including a lit PBR one. Link Materials. */}

## Where does layout happen?

{/* prose: Rust, in integer F26.6 units with one rounding contract; JavaScript owns Unicode analysis and the render
loop. Link How it works. */}

## Ecosystem

- `@react-three/fiber` — the WebGPU entry is the maintained renderer target
- `@react-three/drei` — helpers; environment maps and lights pair well with lit text materials
- `@react-three/uikit` — layout UI; see the integration notes in the repository
- `three/tsl` display nodes — bloom, lens flare, and chromatic aberration through `useRenderPipeline`
