The <a href="/examples/">examples gallery</a> lists every demo used on this site. A card starts when you rest on it,
touch it or focus it, and each has a full-page route, `/examples/?example=<name>`, for recording or inspection.

Each demo is one feature and a few dozen lines. Its source is in the repository under
`site/examples/src/scenes/<name>/`: `scene.tsx` is the React Three Fiber scene that runs, and `three.ts` states the
same thing in plain three.js.

## Showcases

These combine several features. Each links to the guide that explains its main technique.

Type struck into procedural marble. See [Custom materials](/guides/scene/custom-materials).
