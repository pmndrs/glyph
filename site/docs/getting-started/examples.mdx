# Examples

The [examples gallery](/examples/) is the canonical catalog. It is generated from one typed scene table, starts a
card only after you engage it, and provides a focused fullscreen route for every demo. That keeps this documentation
page light while ensuring newly added examples appear in one place rather than in several hand-maintained grids.

## New material studies
