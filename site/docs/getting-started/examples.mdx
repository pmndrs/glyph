<Intro>
  Every example is one feature, one screen, and a few dozen lines. They share a harness that owns the canvas, camera,
  and lighting, so each source file is only the text it demonstrates. Art is generated, not loaded.
</Intro>

Every scene below runs inline, on one renderer shared by the whole page: two run at a time, the nearest to the
middle of the window, and the others keep their last frame. The [gallery](/examples/) has all of them on one page,
started by hand — rest on a card and it runs.

## Showcase

<glyph-proxy root="scenes" data-scene="kinetic" aria-label="Kinetic typography with live shaping" aspect="16 / 9" />

The Codrops piece with the engine where the bitmap font used to be: a line of Slug type — the passage, typing
itself in — is rendered to a render target every frame and wrapped around a lit torus knot with the same
`fract(uv * repeat - time)`; two rings of Slug glyphs orbit it on paths, copied out with `breakApart()` and placed
by matrix, depth-tested so the knot hides them; the word being typed is spotlit above.
