<Intro>
  The same baker that runs in the CLI runs in a module Worker. Give a FontFace a source font and a runtime baker and
  it produces the identical GLB on the client, caching the validated result in CacheStorage. It is the fallback for
  fonts you cannot pre-bake, never the production default.
</Intro>

| Approach | Best for | Tradeoff |
| --- | --- | --- |
| [Pre-baked GLB](./baking) | production, static fonts | one build step, no runtime cost |
| Runtime bake | user-supplied fonts, fast iteration | the baker Wasm and a Worker load on demand; a bake per new font |

```ts
import { glyph } from '@pmndrs/glyph';
import { bakeFontInWorker } from '@pmndrs/glyph/runtime-bake';
import { msdf } from '@pmndrs/glyph/three/msdf';

const Upload = glyph.fontFace(
  { source: '/fonts/Inter-Regular.ttf', runtimeBake: bakeFontInWorker, unicodeRanges: [{ start: 0x20, end: 0x7e }] },
  { format: msdf },
);
await Upload.load();
```

```tsx
const upload = useMsdf({ source: fileUrl, runtimeBake: bakeFontInWorker });
```

## What the Worker does

{/* prose: one request normalizes the Unicode ranges, prepares the source once, feeds the exact prepared bytes to the
shaping bake and every requested raster bake, composes and validates one canonical GLB, transfers it. The GLB's
generator is `@pmndrs/glyph` regardless of producer. */}

## Caching

{/* prose: only the final validated GLB is cached, in CacheStorage. Identity: source bytes, face, normalized ranges,
ordered raster descriptors and keys, format/baker versions. Persistence follows the source response — `no-store`,
`no-cache`, missing freshness, or already-expired stay memory-only; `max-age`/`Expires` set the derived expiration.
Quota eviction, privacy modes, and corruption are transparent misses. */}

## Bundle boundary

{/* prose: the root entry has no static edge to the baker; `@pmndrs/glyph/runtime-bake` is the explicit import that
loads it, split into its own chunk. Nothing reaches the Worker unless a `source` input is used. */}

## A baked GLB never re-bakes

{/* prose: a face member whose exact descriptor a baked GLB does not advertise rejects with
`FONT_FACE_FORMAT_UNAVAILABLE`; runtime baking runs only for a `source` input. Link Raster formats → Options are
identity. */}
