<Intro>
  A FontFace is a declaration: one source, an optional family name, the raster formats you intend to use. `load()` is
  the one load boundary. The declaration is itself its default selection, each declared format is a distinct member,
  and every handle binds the loaded face without loading it again.
</Intro>

## Declare and load

```ts
import { glyph } from '@pmndrs/glyph';

const Inter = glyph.fontFace({ baked: '/fonts/inter.font.glb' }, { family: 'Inter' });
await Inter.load();

const label = three.createText({ font: Inter, text: 'Hello' });
```

{/* prose: one argument is enough — `glyph.fontFace(source)` names the family `Font{n}` and denotes the handle's default
format (MSDF for `ThreeConfig`). `load()` is idempotent and resolves to the same face, so `font: await Inter.load()` is
equivalent. */}

## Formats are members

```ts
import { bitmap } from '@pmndrs/glyph/three/bitmap';
import { msdf } from '@pmndrs/glyph/three/msdf';
import { slug } from '@pmndrs/glyph/three/slug';

const Inter = glyph.fontFace(
  { baked: '/fonts/inter.font.glb' },
  { family: 'Inter', format: [msdf, slug, { raster: bitmap, options: { strikes: [16, 32] } }] },
);

Inter.default === Inter;   // the first declared format is the face's default
Inter.slug !== Inter;      // every other declared format is its own selection
await Inter.slug.load();   // loads only Slug
await Inter.load();        // loads every declared format
await Inter.formats();     // ['bitmap', 'msdf', 'slug'] — what the GLB actually carries, without loading sidecars
```

| Selection | Loads | Use when |
| --- | --- | --- |
| `Inter` / `Inter.default` | the default format | ordinary text |
| `Inter.msdf`, `Inter.slug`, `Inter.bitmap` | that format only | a title in Slug, UI in Bitmap |
| `Inter.load()` | every declared format | you will use several |

{/* prose: a declared member the GLB does not advertise rejects with `FONT_FACE_FORMAT_UNAVAILABLE`; a baked miss never
triggers runtime baking. Options are part of the format: `{ raster: msdf, options: { emSize: 32 } }` matches only a
bake made with those values. */}

## Load before use

> [!IMPORTANT]
> Imperative `createText` and `text.font =` throw synchronously on an unloaded selection. Await the selection first.
> React suspends instead — see below.

```ts
const title = three.createText({ font: await Inter.slug.load(), text: 'Title' });
Inter.slug.isLoaded(); // true, synchronously, after the promise settles
```

## React hooks

```tsx
import { useFont } from '@pmndrs/glyph/react';
import { useMsdf } from '@pmndrs/glyph/react/msdf';
import { useBitmap } from '@pmndrs/glyph/react/bitmap';
import { useSlug } from '@pmndrs/glyph/react/slug';

const body = useMsdf({ baked: '/fonts/inter.font.glb' });
const ui = useBitmap({ baked: '/fonts/inter.font.glb' }, { strikes: [16, 32] });
const title = useSlug({ baked: '/fonts/playwrite.font.glb' });
const custom = useFont({ baked: '/fonts/x.font.glb' }, { format: { raster: myFormat, options } });
```

{/* prose: each hook declares a FontFace through `glyph.fontFace` on the selected handle, checks `isLoaded()` first,
and only then conditionally `use()`s the same stable load promise — a ready font renders without a Promise or a
microtask. The mounted component owns an independent `Font` lease. */}

### Preload

```ts
useMsdf.preload({ baked: '/fonts/inter.font.glb' }); // Promise<void>, at module scope
```

{/* prose: starts the default handle's load before render; the hook later finds it loaded. `.clear()` drops the
hook's declaration cache and disposes the face it declared; a mounted lease is unaffected. */}

## Strings and the provider

```tsx
<GlyphProvider fontFaces={{ Inter: '/fonts/inter.font.glb', Title: { src: titleUrl, format: slug } }}>
  <Text font="Inter">Hello</Text>
  <Text font="Title">Hello</Text>
</GlyphProvider>
```

{/* prose: a string resolves through the nearest provider's `fontFaces` table, then the root catalog by family; an
unknown name throws `FONT_FACE_NOT_FOUND`. The table declares names; it does not gate loading — a resolved selection
still follows the same isLoaded/use path. Supplying `fontFaces` adds a local Suspense boundary. */}

## Sources

| Source | Resolves to |
| --- | --- |
| `'/fonts/inter.font.glb'` or a `URL` ending in `.glb` | baked only; a miss is `BAKED_FONT_MISSING` |
| `'/fonts/Inter.ttf'` or any other URL | the source font, and a probe for the sibling `Inter.font.glb`; a missing sibling warns in development and bakes at runtime |
| `{ baked: url \| Request \| bytes }` | baked only |
| `{ source: url \| bytes, baked: null }` | the source with no sibling probe |
| `{ source, runtimeBake, unicodeRanges? }` | baked on the client, optionally subset first — see [Runtime baking](/docs/fonts/runtime-baking) |
| `Blob` | an in-memory font |
| `SerializedFontFace` | a face cloned from another realm — see below |

One content-addressed graph backs every face and handle: two declarations over the same URL share one fetched
artifact and acquire only the raster artifacts their selected formats request. Family names are aliases, never
cache keys.

## Errors

| Code | When |
| --- | --- |
| `BAKED_FONT_MISSING` | a baked-only source answered 404 or 410 |
| `BAKED_FONT_FETCH` | any other HTTP failure |
| `BAKED_FONT_INVALID`, `BAKED_FONT_INCOMPATIBLE` | the bytes are not a `PMNDRS_font` GLB, or its version pins do not match this runtime |
| `BAKED_FONT_RESOURCE_LIMIT` | over 64 MiB, more than 4096 buffer views, or more than 256 rasters |
| `FONT_FACE_FORMAT_UNAVAILABLE` | the declared format and options name a raster key the file does not carry |
| `FONT_FACE_FORMAT_REQUIRED` | `load()` found no declared or decodable format |
| `FONT_FACE_FORMAT_NOT_LOADED` | imperative `createText` on a selection that has not loaded |
| `RUNTIME_BAKER_UNAVAILABLE` | a source font needed baking and the runtime baker could not be imported |

`face.load()` loads every declared format and every format the file advertises for which a decoder module has been
imported; `face.slug.load()` loads one. Decoding rechecks each raster's identity, validates the record table and
its KTX2 pages, and enforces a 256 MiB texture budget. GPU upload happens on first draw.

## Across realms

```ts
const [serialized, transfer] = await Inter.slug.clone();
worker.postMessage(serialized, transfer);
// worker:
const Inter = glyph.fontFace(serialized);
```

{/* prose: an explicit data clone of the loaded main GLB and the selected format's dependencies into fresh buffers;
nothing ordinary ever copies font bytes. */}

## Lower-level loaders

```ts
import { loadFont, createFontStack, createFontLibrary } from '@pmndrs/glyph';
import { FontLoader } from '@pmndrs/glyph/three';
```

{/* prose: `loadFont(input, format, options?)` and the tuple form return immutable `Font` values without a FontFace —
for renderer-free `Paragraph` measurement, custom integrations, and stacks; `createFontLibrary` is an explicit cache
with leases; the Three `FontLoader` adapts to `LoadingManager`. All of them enter the same resource graph. */}

## Ownership

| Object | Dispose when | Then |
| --- | --- | --- |
| `Text` | it leaves the scene for good | its font lease releases |
| `FontFace` | no text or hook uses it | pending loads abort; its graph leases release |
| handle | the adapter is finished | after existing leases end |

{/* prose: a face disposed before its text keeps the text alive until the text disposes — leases are counted.
Disposal is the correctness mechanism; finalizers are only a safety net for abandoned React roots. */}
