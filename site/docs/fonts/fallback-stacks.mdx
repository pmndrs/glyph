<Intro>
  A stack is an ordered list of loaded fonts. The engine resolves each grapheme cluster against the first font that
  covers it, so one paragraph can mix a Latin face, an icon font, and a CJK face without the caller choosing per
  character.
</Intro>

```ts
import { createFontStack, loadFont } from '@pmndrs/glyph';
import { slug } from '@pmndrs/glyph/three/slug';

const interSlug = await loadFont({ baked: '/fonts/Inter.font.glb' }, slug);
const emoji = await loadFont({ baked: '/fonts/Emoji.font.glb' }, slug);

const prose = createFontStack(interSlug, emoji);
scene.add(three.createText({ font: prose, text: 'Status 🌍' }));
```

```tsx
const prose = createFontStack(useMsdf(INTER), useMsdf(ICONS), useMsdf(CJK));
<Text font={prose}>Status 🌍 你好</Text>
```

## Resolution

{/* prose: per extended grapheme cluster, the first font in order that covers every code point of the cluster; a
cluster no font covers renders the primary's notdef and counts in `measure().missingGlyphCount`. Formats may differ
per font in one stack — the render plan partitions draws by format and resource. A stack takes loaded `Font` values:
the ones hooks return, or `loadFont` results. */}

## Icon fonts

```tsx
<Text font={prose}>
  Hello world <Text font={icons}>{''}</Text>
</Text>
```

{/* prose: bake only the glyphs you use (`glyph glyphs --unicode-set`); a nested `<Text font={…}>` overrides the
face for a run without a stack; a stack is for when you do not know where the icons fall. */}

## CJK

{/* prose: use TrueType faces (M PLUS 1p, Nanum Gothic, ZCOOL XiaoWei on the landing); CFF-only Noto Sans CJK
produces no outlines through the current baker — tracked upstream. Line breaking follows UAX 14 with CJK
Script_Extensions resolved from context. Vertical layout is not yet supported. */}

## Emoji

{/* prose: Slug renders outline emoji faces; color emoji (COLR/CBDT) are not supported. */}

## Leading across faces

> [!WARNING]
> `lineHeight` is resolved per cluster and clamps leading at zero, so a face with tall ascent/descent (Myanmar,
> Arabic Noto statics) opens the line it lands on. Prefer faces with similar vertical metrics in one stack, or
> set an explicit `lineHeight` large enough for the tallest.

## Typing

import type { FontStack } from '@pmndrs/glyph';
